# 그릇·테이블·편의 선택·인게임 불 슬라임 계획

## 구현 범위

- 라운드마다 고유 ID를 가진 깨끗한 그릇을 생성하고, 완성 음식을 그릇에
  담아야만 제출되도록 조리 흐름을 연결한다.
- 제출 뒤 더러운 그릇을 세척기에 맡기고 물 슬라임이 세척해 다시 쓰는
  순환을 구현한다.
- 한 칸 테이블에서 재료와 모든 상태의 그릇을 내려놓고 다시 집는다.
- 일반 좌클릭 교체, Shift 좌클릭 토글, 빈 공간 클릭 해제, 드래그 범위
  선택, Q/W/E/R/Space 선택을 함께 지원한다. ESC는 설정을 열고 선택을
  유지한다.
- `fire_slime.svg`를 실제 Phaser 게임의 불 슬라임 텍스처로 사용하고 기존
  숨쉬기·이동·작업 tween에 연결한다.
- 선택 카드의 물·불 슬라임은 같은 탄성 주기와 변형값을 사용하며, 불꽃이
  카드 위에서 잘리지 않도록 표시 영역을 확보한다.

## 임시 설정값과 열린 질문

- 명세가 값 자체를 미정으로 둔 항목은 `dishConfig`에 모은다. 첫 검증값은
  초기 그릇/생성대 수용량 3, 세척기 수용량 1, 세척 4초, 땅 슬라임 그릇
  운반 2개, 테이블 수용량 1, 드래그 최소 거리 8px이다.
- 테이블을 한 칸으로 두어 여러 물건이 있을 때 임의 순서로 집는 동작은
  만들지 않는다.
- 음식 폐기 뒤 그릇 복구 규칙, Shift+단축키 추가 선택, 드래그 경계 판정,
  재개 카운트다운 사용 여부는 확정 전까지 현재 최소 동작으로 유지한다.

## 구현하지 않는 범위

- 별도 그릇/테이블 원화 제작, 물리 충돌, 아이템 직접 클릭, 작업 예약 큐
- 아직 게임에 없는 사망·제거와 그때의 그릇 드롭
- 여러 칸 테이블에서 특정 보관 위치를 고르는 새 UI

## 완료 조건

- `생성대 → 운반 → 완성 음식 담기 → 제출 → 오염 → 세척 → 재사용`이
  결정론 코어 테스트와 실제 게임에서 이어진다.
- 테이블에 둔 아이템·그릇의 ID, 상태, 내용물이 보존된다.
- Shift/드래그/단축키/ESC 선택 동작이 기존 우클릭 명령과 충돌하지 않는다.
- 인게임 불 슬라임이 원본 몸통 형태와 불꽃을 유지한 채 방향, 이동, 작업
  상태 변화에 반응하고 물 슬라임과 몸통 크기가 맞는다.
- 선택 카드 불꽃이 잘리지 않고 물·불 탄성 애니메이션이 같은 기준을 쓴다.
- 테스트, 린트, 프로덕션 빌드, 여러 브라우저 크기의 실제 동작 검증을
  통과한 뒤 현재 배포 프로젝트에 반영한다.
