# 아르바이트 스테이지 선택 화면 계획

## 범위

- 모드 선택에서 아르바이트 모드를 누르면 0~3 스테이지 선택 화면을 연다.
- 0은 튜토리얼로 별도 색과 이름을 표시하고 항상 선택할 수 있게 한다.
- 1~3은 직전 스테이지를 한 번 이상 완료했을 때 순서대로 해금한다.
- 잠긴 스테이지는 숫자를 숨기고 제공된 자물쇠를 표시하며 버튼 전체를 어둡게 한다.
- 제공된 제목·정사각형 버튼·자물쇠 에셋을 `public/ui/` 파생본으로 적용한다.
- 기존 이어하기 확인창과 다음 스테이지 저장값은 제거한다. 기존 쿠키에서는 최고
  별 기록만 그대로 읽고, 선택 화면에서 사용자가 열린 판을 직접 고른다.
- 정산창의 `영업 종료` 제목만 몇 픽셀 아래로 내린다.
- 0~3 숫자는 글꼴 대신 제공된 숫자 그림을 사용한다. 0은 사용자가 추가한
  무명 원본의 파생본으로 이름을 정리한다.
- 튜토리얼 구분은 숫자 색이 아니라 0번 나무 버튼 판 자체의 색을 바꿔 표현한다.
- 승리 정산의 `튜토리얼 완료`, `N 스테이지 클리어` 글자를 각각 제공된
  `튜토리얼 클리어`, 숫자 + `스테이지 클리어` 그림으로 교체한다.

## 완료 조건

- 첫 실행에는 튜토리얼만 열리고 1~3에는 숫자 대신 자물쇠가 보인다.
- 0 완료 후 1, 1 완료 후 2, 2 완료 후 3이 차례로 열린다.
- 열린 스테이지를 누르면 해당 ID로 시작하며 별도 이어하기 팝업이 나오지 않는다.
- 모드 화면과 스테이지 화면의 뒤로가기가 각각 홈과 이전 화면으로 동작한다.
- 모바일 가로와 데스크톱에서 네 버튼과 제목이 뷰포트 안에 들어온다.
- 승리 정산에 HTML 글자 대신 클리어 문구·숫자 그림이 표시되고 접근 가능한
  숨김 제목은 남는다.
- 테스트, typecheck, lint, Pages 빌드와 실제 브라우저 검증을 통과한다.

## 구현·검증 결과

- `PASS`: 아르바이트 모드를 누르면 새 제목 아래 0~3 정사각형 카드가 나온다.
  첫 기록에서는 초록색 튜토리얼 0만 열리고 1~3은 숫자 대신 어두운 자물쇠가 보인다.
- `PASS`: 직전 스테이지의 별이 1개 이상일 때만 다음 ID가 열리는 상태 테스트를
  추가했다. 열린 카드는 해당 ID로 바로 시작하고 이어하기 확인창은 제거했다.
- `PASS`: 스테이지 화면의 뒤로는 모드 선택으로 돌아가고, 튜토리얼 0을 누르면
  점장 도입 대사로 진입하는 것을 Pages 정적 화면에서 확인했다.
- `PASS`: `영업 종료` 그림을 4px 내렸다. 테스트 58/58, typecheck, lint,
  diff 검사와 Pages 빌드를 통과했다.
- `PASS`: 0~3 카드의 글꼴 숫자를 제공된 숫자 그림으로 교체하고, 튜토리얼
  0번은 숫자색이 아닌 나무판 전체를 녹색 계열로 바꿨다.
- `PASS`: 0 원본만 불투명 검은 배경이 있어 BG Wiper adaptive 엔진으로 제거했다.
  품질 점수 0.950604, 상태 `pass`, 유효 전경 1개를 확인한 뒤 256px 파생본을 썼다.
- `PASS`: 승리 정산은 튜토리얼에서 `튜토리얼 클리어`, 일반 판에서 숫자와
  `스테이지 클리어` 그림을 조합한다. 접근성용 숨김 제목은 유지했다.
