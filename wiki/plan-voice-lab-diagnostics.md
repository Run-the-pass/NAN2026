# 음성 실험실 매칭 근거·정리 계획

## 확인된 결정

- 확정 원문은 주 처리 방식을 `오디오 → Gemini → 명령 JSON`으로 두고,
  브라우저 실시간 자막은 디버깅 참고 정보이며 명령 입력으로 사용하지
  않는다고 명시한다.
- 2026-07-28 Claude 구현에서 브라우저 STT를 로컬 사전에 먼저 넣고,
  불일치 텍스트를 Gemini에 다시 보내는 폴백이 추가됐다. 이는 위 원문과
  어긋나므로 제거한다.
- 브라우저 STT를 쓰는 현재 경로는 로컬 사전까지만 처리한다. Web Speech
  API 미지원 시 녹음한 원본 오디오를 Gemini에 보내는 경로는 유지한다.

## 범위

1. 사전 검사를 actor, 색상, 물품, 목적지별로 나누어 감지된 표현과 표준
   의미를 반환한다. 호칭이 없으면 첫 슬라임이 기본 대상임을 표시한다.
2. 음성 실험실의 현재 결과와 최근 기록에서
   `감지된 표현 → 표준 의미`를 확인한다.
3. 기존 STT 원문으로 현재 사전을 다시 검사해 표시한다. 별도 DB 열이나
   마이그레이션은 추가하지 않는다.
4. 인증된 음성 결과 API에 양의 정수 ID 하나를 삭제하는 기능을 추가하고,
   화면에서는 `삭제 → 정말 삭제`의 2단계 확인 뒤 해당 행만 삭제한다.
5. `/api/command`는 텍스트 입력을 받지 않고 8MB 이하 오디오만 받는다.
6. 음성 실험실의 푸시투토크 키는 게임과 구분해 `E`로 사용한다.

## 완료 조건

- `붉은 양초 양쪽에`가 `붉은→붉은색`, `양초→약초`,
  `양쪽→양조기`, `호칭 없음→첫 슬라임`으로 설명된다.
- 브라우저 STT 불일치 텍스트가 Gemini로 전송되지 않는다.
- 원본 오디오 Gemini 경로는 기존 allowlist 검증과 함께 동작한다.
- 사용자가 화면 내 2단계 확인을 거쳐 결과 한 건을 삭제할 수 있고, 잘못된
  ID와 없는 ID는 각각 400과 404로 거부된다.
- 테스트, 변경 파일 lint, 빌드와 브라우저 검증을 통과한다.
- 음성 실험실에서 `E` 누름부터 뗌까지 한 발화만 저장한다.
