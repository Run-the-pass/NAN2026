# 효과음·불 슬라임·미사용 client 에셋 정리 계획

## 구현 범위

- 현재 게임 상태로 판정 가능한 UI, 라운드, 주문, 조리, 운반, 화재,
  슬라임 선택·이동 이벤트에 대응 효과음을 연결한다.
- `A07_food_ready`는 조리 완료가 아니라 올바른 음식 제출에 사용한다.
- 발화 원샷과 화재 루프를 분리하고 진압 시 루프를 중지한다.
- 시스템이 없는 설거지·도마질·쓰레기 소각 효과음은 `raw`에만 보존한다.
- `fire_slime.svg`를 선택 카드에 적용하고, 불꽃을 제외한 몸통이 물 슬라임
  몸통과 같은 크기로 보이도록 별도 표시 상자와 탄성 애니메이션을 적용한다.
- 코드·CSS·메타데이터에서 참조되지 않는 기존 `public/` 에셋만 삭제한다.

## 구현하지 않는 범위

- 설거지·도마질·쓰레기 소각 게임 시스템
- 별도 효과음 음량 설정 UI, 공간 음향, 오디오 크로스페이드
- 방향별 불 슬라임 원본 SVG 제작

## 완료 조건

- 구현된 이벤트마다 대응 효과음이 한 번 재생되고 복수 선택 시 과도하게
  겹치지 않는다.
- 음식 제출 시 `A07_food_ready`, 조리 시작 시 `A01_grill`이 재생된다.
- 화재 발생 시 원샷 뒤 루프가 유지되고 진압 시 중지된다.
- 불 슬라임 선택 카드에서 불꽃은 보존되며 몸통 크기는 물 슬라임과 맞는다.
- 삭제한 client 에셋은 전체 참조 검색에서 미사용이고 빌드 결과에 필요 없다.
- 테스트, 린트, 프로덕션 빌드와 브라우저 실제 동작 검증이 통과한다.
