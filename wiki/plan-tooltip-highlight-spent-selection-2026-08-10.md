# 설명 UI·이동 하이라이트·행동력 0 선택 보정 계획

## 범위

- `base.png`에 쓰는 CSS 9분할 방식을 `base2.png`에도 그대로 적용해 호버·키보드 포커스 설명과 거절 토스트의 배경으로 쓴다.
- 이동 가능 타일의 채움·외곽선 색을 현재 선택한 슬라임의 속성색으로 표시한다.
- 행동력 0인 슬라임을 직접 고르면 선택·상세 정보는 유지하되 이동·상호작용은 계속 막는다.

## 제외 범위

- 설비 상호작용 가능·불가의 초록색·빨간색 표시는 바꾸지 않는다.
- 행동력 소진 뒤 다음 슬라임 자동 선택과 자동 턴 종료 규칙은 바꾸지 않는다.
- `raw/` 원본은 수정하지 않는다.

## 완료 조건

- 호버 설명과 토스트가 `base2.png`의 모서리를 찌그러뜨리지 않고 내용 길이에 맞춰 늘어난다.
- 땅·물·불·번개 슬라임의 이동 가능 칸이 각 슬라임 색으로 바뀐다.
- 행동력을 모두 쓴 슬라임을 로스터와 지도에서 다시 눌러 선택할 수 있고, 이 선택 때문에 자동으로 다른 슬라임이나 다음 턴으로 넘어가지 않는다.
- 행동으로 행동력 0이 된 경우에는 기존처럼 다음 슬라임을 자동 선택한다.
- 테스트·타입 검사·린트·Pages 빌드와 브라우저 실제 동작 검증을 통과한다.
