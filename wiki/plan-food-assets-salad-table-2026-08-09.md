# 음식 에셋·테이블 샐러드 조합 보정 계획

## 범위

- `raw/에셋3/`의 감자튀김·샐러드·채 썬 감자·당근·양배추를 투명 여백만
  잘라 기존 `public/food/` 그림과 교체한다. 원본은 수정하지 않는다.
- 주문 카드, 다음 주문, 슬라임 소지품, 테이블 위, 정보 패널에서 같은 그림을
  재사용하고 접시와 내용물이 서로 가리지 않는 크기로 맞춘다.
- 썬 당근과 썬 양배추 중 하나가 테이블에 있고 다른 하나를 들고 테이블을
  사용하면 접시 없이 낱개 샐러드로 합쳐지게 한다. 제출에는 기존처럼 접시가
  필요하다.
- 튜토리얼 턴 종료 및 지도 화살표는 엉뚱한 이동 뒤에도 목표 바깥에 고정되는지
  실제 플레이로 다시 확인한다.

## 하지 않는 범위

- 무한 모드의 주문 생성·난이도·종료 규칙은 아직 확정되지 않아 구현하지 않는다.
- 음식별 개별 렌더러나 새 에셋 의존성을 추가하지 않는다.

## 완료 조건

- 새 음식 다섯 장이 투명 여백을 제외한 256px 이하 파일로 교체되고 첫 화면
  프리로드 목록 검증을 통과한다.
- 접시가 슬라임 손과 테이블에서 이전보다 크게 보이고, 주문 카드와 접수대 합성에서
  음식이 접시 안에 들어간다.
- 접시 없는 `썬 당근 + 썬 양배추 → 샐러드` 테스트와 기존 접시 조합·제출 테스트가
  모두 통과한다.
- 가로 모바일과 데스크톱에서 주문 카드·테이블·튜토리얼 화살표를 확인하고 결과를
  플레이 흐름 보고서에 남긴다.

## 검증 결과

**PASS**

- 다섯 음식 그림을 투명 여백 기준으로 잘라 긴 변 256px, 38~48KB PNG로 교체했다.
  주문 카드와 다음 주문에서는 접시 안쪽에 들어가고, 슬라임 손의 접시는 24px,
  테이블 위 접시는 약 34px로 키워 내용물과 분리해 보이게 했다.
- 접시 없는 썬 당근·썬 양배추가 테이블에서 낱개 샐러드로 합쳐지고, 기존 접시
  조합과 접시 필수 제출 규칙이 함께 통과한다.
- 실제 튜토리얼 완주에서 비허용 이동 뒤에도 같은 cue의 화살표 좌표가 고정됐다.
  턴 종료 안내창은 버튼 위로 올렸고, 테이블에서 접시를 합치고 회수하는 화살표는
  오른쪽 외곽에 두어 퐁당이와 겹치지 않는다.
- `npm test` 57/57, typecheck, lint, `git diff --check`와 캐시를 비운 Pages
  빌드가 통과했다.
