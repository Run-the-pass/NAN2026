# 3분 마도서 제작 펀테스트

## 현재 목표

음성으로 슬라임에게 여러 단계 작업을 지시하고, 두 솥의 진행 상태와 타이밍을 관리하는 행위가 재미있는지 검증한다.

```text
3분 안에 마도서 8권 납품
```

## 최소 범위

- 고정 마법 공방 맵 1개
- 슬라임 1마리
- 약초 상자, 양피지 상자, 솥 2개, 납품대 1개
- 음성 명령에 따른 이동과 물건 운반
- 솥별 5초 조합과 5초 각인
- 완성된 마도서 회수와 납품
- 작업 상태와 명령 인식 결과 피드백

## 테스트 레시피

```text
약초 가져오기
→ 솥에 약초 넣기
→ 섞기
→ 5초 대기
→ 양피지 가져오기
→ 양피지 담그기
→ 5초 대기
→ 마도서 회수
→ 납품
```

## 원자 명령

`GET_HERB`, `ADD_HERB`, `MIX`, `GET_PARCHMENT`,
`DIP_PARCHMENT`, `TAKE_BOOK`, `SUBMIT`만 허용한다.

솥 작업은 `cauldron-01` 또는 `cauldron-02`를 반드시 지정한다. Gemini는
이 허용 목록 안에서 의도만 구조화하고, 순서 검증과 결과는 게임 코어가
결정한다.

## 현재 비활성

- 반복 주문과 주문별 제한 시간
- 서빙 역할과 손님 동선
- 매출, 가격, 고용비, 금전 패널티
- 라운드 사이 업그레이드와 성장 선택
- 슬라임 종류별 스탯 차이
- 다수 슬라임, 팀 명령, 복수 레시피

스탯 문서의 작업 속도·이동 속도·청력·집중력 레벨 표는 장기 밸런스 기준으로 보존하되 첫 펀테스트에는 적용하지 않는다.

## 구현 상태

- 16×10 공방 맵과 말랑 1마리
- 독립 상태와 타이머를 가진 솥 2개
- 속도 기반 BFS 이동과 FIFO 작업 큐
- 소지품, 솥 상태, 현재 작업과 큐를 보여 주는 맵·HUD
- 180초 제한과 8권 납품 성공 판정
- 동일 코어를 사용하는 디버그 버튼, Gemini 명령, CLI 테스트
