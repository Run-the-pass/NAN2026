# 3분 마법서 제작 펀테스트

## 현재 목표

음성으로 슬라임에게 여러 단계 작업을 지시하고, 두 가마솥의 진행 상태와 타이밍을 관리하는 행위가 재미있는지 검증한다.

```text
3분 안에 테스트용 마법서 8장 제작
```

## 최소 범위

- 고정 마법 공방 맵 1개
- 슬라임 1마리
- 초록 약초 박스, 양피지 박스, 가마솥 2개, 제출대 1개
- 음성 명령에 따른 이동과 물건 운반
- 가마솥별 5초 섞기와 5초 각인
- 완성된 마법서 회수와 제출
- 작업 상태와 명령 인식 결과 피드백

## 테스트 레시피

```text
초록 약초 투입
→ 섞기
→ 5초 대기
→ 양피지 담그기
→ 5초 대기
→ 마법서 회수
→ 제출
```

## 현재 비활성

- 반복 주문과 주문별 제한 시간
- 서빙 역할과 손님 동선
- 매출, 가격, 고용비, 금전 패널티
- 라운드 사이 업그레이드와 성장 선택
- 슬라임 종류별 스탯 차이
- 다수 슬라임, 팀 명령, 복수 레시피

스탯 문서의 작업 속도·이동 속도·청력·집중력 레벨 표는 장기 밸런스 기준으로 보존하되 첫 펀테스트에는 적용하지 않는다.

## 현재 코드와의 차이

현재 코드는 식당 프로토타입이며 말랑·빨강 2마리, 버섯 스튜, 10초 주문, 서빙, 성장 카드와 75초 라운드를 사용한다. 타일 BFS, 속도 기반 이동, FIFO 작업 큐, 렌더링 독립 코어는 펀테스트에서도 재사용할 수 있다.

다음 구현은 기존 코어를 유지하면서 콘텐츠와 승리 조건을 1마리·2가마솥·3분·마법서 8장으로 교체하는 별도 계획이 필요하다.
