# 튜토리얼 턴·화살표 재검증 계획

## 범위

- 첫 양배추 제출까지 실제 순서로 플레이하며 매 단계의 지목 슬라임, 소지품,
  목표 설비와 턴 전환을 확인한다.
- 지목된 슬라임의 행동력이 없을 때 다른 슬라임에게 같은 설비 일을 시키지는
  않되, 공개된 다른 슬라임은 자유롭게 이동할 수 있다. 모두 행동했거나 쉬기를
  선택하면 튜토리얼도 일반 게임처럼 자동으로 턴을 넘긴다.
- 물 슬라임은 깨끗한 접시를 든 뒤에만 테이블 합치기 안내를 받게 한다.
- 테이블·그릇 상자 화살표를 목표와 접근 칸을 가리지 않는 외곽으로 옮긴다.
- 행동 중 안내 대화창은 물 슬라임과 하단 설비를 가리지 않는다.
- 튜토리얼 차단 시 표시하던 `노란색 화살표가 가리키는 곳부터` 토스트는 제거한다.
- 퐁당이는 등장 직후 접시를 먼저 집고, 이후 푸름이가 음식을 테이블로 옮긴다.
- 행동력 설명은 턴 종료 버튼까지 드러나게 줄이고 슬라임 선택 버튼을 강조한다.
- 짧은 행동 안내는 우측 정보 창을 덮지 않고 하단 HUD의 남는 공간에 표시한다.
- 맵 화살표는 Phaser 캔버스보다 높은 DOM 레이어에 고정한다.
- 게임·홈·선택·대화 화면의 글자 선택과 이미지 기본 드래그를 막는다.

## 하지 않는 것

- 튜토리얼 행동을 자동 실행하거나 필요한 물건을 강제로 생성하지 않는다.
- 일반 스테이지의 자동 슬라임 선택과 턴 규칙은 그대로 사용한다.

## 완료 조건

- 푸름이 손질 → 퐁당이 접시 획득 → 푸름이 테이블 전달 → 테이블 합치기 → 접시 회수
  → 제출 순서가 뒤바뀌지 않는다.
- 현재 목표와 무관한 슬라임이 대신 이동하거나 설비를 쓰라는 안내가 나오지 않는다.
- 목표 슬라임의 행동력이 없어도 다른 공개 슬라임을 움직일 수 있고, 모두 소진되면
  턴이 자동으로 줄어든다.
- 테이블과 그릇 상자 화살표가 설비 또는 필수 이동 칸을 덮지 않는다.
- 물 슬라임 행동 안내가 물 슬라임과 그릇 상자·세척대·테이블을 가리지 않는다.
- 행동력 설명 중 슬라임 선택 버튼과 턴 종료 버튼이 보이고, 우측 정보 내용은
  짧은 안내에 가려지지 않는다.
- 퐁당이가 등장한 직후 그릇 상자를 눌러 접시를 집을 수 있으며, 이후 안내가
  음식 전달과 합치기 순서로 이어진다.
- 튜토리얼 화살표가 맵 배경 뒤로 내려가지 않고, UI 글자·그림을 드래그해
  선택할 수 없다.
- 상태 흐름 테스트와 실제 가로 화면 플레이를 통과한다.

## 결과

- 이전 결과의 “턴 종료만 기다린다”는 판정은 사용자 의도와 달라 폐기한다.
  다른 슬라임에게 같은 설비를 강제하지 않으면서 자유 이동과 자동 턴을 유지해야 한다.
- `PASS`: 상태 흐름을 처음부터 제출까지 재생해 접시가 없을 때
  `TAKE_CLEAN_DISH`, 접시를 든 뒤 `PLATE_AT_TABLE`이 나오는 것을 확인했다.
- `PASS`: 테이블 안내는 목표 아래 한 타일 밖, 그릇 상자는 맵 하단 외곽에서
  위를 가리켜 설비와 필수 접근 칸을 덮지 않는다.
- `PASS`: 지목된 슬라임이 행동력을 다 쓰면 남은 공개 슬라임을 자동 선택하고,
  전원이 소진되면 일반 게임과 같은 경로로 턴을 자동 종료한다. 지목 외 슬라임은
  자유 이동만 가능하며 현재 단계의 설비 상호작용은 계속 막는다.
- `PASS`: 데스크톱 행동 안내는 게임판 밖 우측 정보 레일로 옮겨 퐁당이와 그릇
  상자·세척대·테이블을 가리지 않는다. 모바일 가로에서는 물 안내를 지도 위쪽,
  땅 안내를 아래쪽에 두어 현재 작업 영역과 분리한다.
- `PASS`: 테스트 57/57, typecheck, lint, diff 검사와 Pages 빌드를 통과했다.
- `PASS`: 퐁당이 등장 직후 `TAKE_CLEAN_DISH`를 먼저 안내하고 실제 그릇 상자
  클릭으로 접시를 얻은 뒤, 푸름이 음식 전달 → 합치기 → 회수 → 제출까지 완주했다.
- `PASS`: 행동력 설명은 슬라임 선택·턴 종료 버튼 오른쪽에 표시하고 선택 버튼을
  강조했다. 짧은 안내는 하단 HUD로 옮겨 우측 정보 창을 가리지 않는다.
- `PASS`: 차단 토스트를 제거하고 맵 화살표를 캔버스보다 앞으로 올렸다. 전역
  글자 선택·이미지 드래그 방지도 브라우저 계산 스타일로 확인했다.
- `PASS`: 테스트 58/58, typecheck, lint, Pages 빌드와 1280×720 직접 완주를 통과했다.
- `FIX → PASS`: 퐁당이를 테이블 오른쪽으로 우회시키면 합치기·회수 화살표가
  몸을 가리는 문제를 재현했다. 두 화살표를 테이블 아래 왼쪽 외곽 고정 좌표로
  옮기고 같은 경로로 다시 완주해 슬라임·이동 칸과 겹치지 않음을 확인했다.
