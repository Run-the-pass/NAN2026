# NAN 2026

## 한 문장

플레이어가 음성으로 슬라임 한 마리에게 마도서 제작 작업을 지시하고 두
솥의 타이밍을 관리하여, 3분 안에 마도서 8권을 납품하는 Phaser 3
펀테스트.

## 현재 플레이 흐름

```text
약초 가져오기
→ 솥에 약초 넣기
→ 젓기
→ 5초 조합
→ 양피지 가져오기
→ 솥에 양피지 담그기
→ 5초 각인
→ 마도서 꺼내기
→ 납품
```

- 맵에는 말랑 1마리, 약초 상자, 양피지 상자, 솥 2개, 납품대가 있다.
- 말랑은 명령을 FIFO 큐에 넣고 `IDLE → MOVING → WORKING` 순서로
  실행한다.
- 이동은 16×10 공방 타일에서 고정 순서 BFS 경로와 이동 속도로 계산한다.
- 두 솥은 각각 독립적인 상태와 5초 타이머를 가진다.
- 잘못된 순서의 작업은 재료·솥·납품 상태를 바꾸지 않고 이유를 알린다.
- 180초 안에 8권을 납품하면 즉시 성공하고, 시간이 끝나면 실패한다.

자세한 범위와 보류 항목은 [3분 마도서 제작 펀테스트](fun-test.md)를
따른다.

## 명령 책임 경계

```text
마이크 → 오디오 → Gemini → 후보로 제한된 명령 JSON
→ 게임 코어의 순서·상태 검증 → Phaser 실행
```

- actor는 `slime-01`만 허용한다.
- action은 `GET_HERB`, `ADD_HERB`, `MIX`, `GET_PARCHMENT`,
  `DIP_PARCHMENT`, `TAKE_BOOK`, `SUBMIT`만 허용한다.
- target은 현재 상자, 두 솥, 납품대 중 action에 맞는 대상만 허용한다.
- Gemini는 의도를 구조화할 뿐 작업 성공 여부와 결과를 정하지 않는다.

## 구현 원칙

- Phaser 3, TypeScript, 데스크톱 웹 브라우저를 사용한다.
- 브라우저와 이미 설치된 기능을 우선하며 새 의존성을 추가하지 않는다.
- 규칙과 상태 전이는 렌더링에서 분리해 CLI와 테스트에서 실행한다.
- 동일한 seed, 명령, 경과 시간은 동일한 결과를 만든다.
- 기능은 계획, 작업, 검증 순서로 진행한다.

## 현재 구현

- 고정 공방 맵, 플레이어 직접 이동, 말랑의 속도 기반 장애물 우회
- 말랑의 원자 명령 7종, FIFO 작업 큐, 소지품
- 두 솥의 독립 상태 전이와 자동 타이머
- 맵의 소지품·완성품 아이콘과 HUD의 솥·슬라임·최근 사건 표시
- 180초 제한, 8권 성공, 시간 만료 실패와 재시작
- 오디오를 Gemini 명령 JSON으로 바꾸는 API와 서버 allowlist 검증
- 같은 코어를 실행하는 CLI와 결정론 테스트

## 첫 펀테스트에서 제외

- 작업·이동·청력·집중력 레벨과 가격
- 다수 슬라임, 역할 분담, 복합·팀 명령
- 복수 레시피, 복수 맵, 장기 성장, 저장
- 반복 요청, 손님 동선, 매출

이전 프로토타입 구현 이력은 [작업 로그](log.md)에만 보존한다.

## 남은 외부 설정

- 실제 음성 명령에는 배포 환경의 `GEMINI_API_KEY`가 필요하다.
