# NAN 2026

## 한 문장

플레이어가 마우스와 키보드로 속성이 다른 슬라임을 선택·지휘해
버섯 구이를 만들고 3분 동안 주문을 채우는 Phaser 3 펀테스트.

## 현재 플레이 흐름

```text
첫 속성 슬라임 선택
→ 좌클릭 또는 속성 키로 슬라임 선택
→ 재료 상자를 우클릭해 버섯 집기
→ 조리 도구를 우클릭해 버섯 넣기
→ 불 슬라임으로 조리하고 버섯 구이 집기
→ 제출대를 우클릭해 납품
```

- 새 조작 명령은 기존 작업을 교체한다.
- 슬라임은 `IDLE → MOVING → WORKING/WAITING → IDLE`을 실행한다.
- 불 슬라임은 재료가 없는 조리 도구 앞에서 기다리고, 버섯이 들어오면 자동으로 작업한다.
- 조리 도구는 한 번에 한 마리만 작업하며 작업자와 진행도를 표시한다.
- 현재 소지품은 슬라임 위 아이콘으로 표시한다.

## 조작

- 좌클릭: 슬라임 한 마리 선택, 빈 바닥에서 선택 해제
- 바닥 우클릭: 선택된 슬라임이 클릭한 유클리드 좌표까지 직선 이동
- 설비 우클릭: 선택된 슬라임이 작업 타일로 이동한 뒤 상호작용
- `Q`: 물, `W`: 불, `E`: 번개, `R`: 땅 속성 전체 선택
- `Space`: 현재 조작 가능한 모든 슬라임 선택

슬라임 ID와 표시 이름은 물·불·번개·땅으로 통일한다. 각 속성은 식당
업무에 맞는 독립 스탯과 역할 설명을 가진다.

## 구현 원칙

- Phaser 3, TypeScript, 데스크톱 웹 브라우저를 사용한다.
- 브라우저와 이미 설치된 기능을 우선하며 새 의존성을 추가하지 않는다.
- 규칙과 상태 전이는 렌더링에서 분리해 CLI와 테스트에서 실행한다.
- 같은 seed, 스쿼드, 조작, 경과 시간은 같은 결과를 만든다.
- 기능은 계획, 작업, 검증 순서로 진행한다.

## 현재 구현

- 새 `슬라임 레스토랑` 로고와 기존 책상·가마솟·거품·슬라임 배치의 홈 화면
- 홈·인게임 상단 음악 설정 탭, 음악 켜기·끄기·음량 저장
- 고정 식당 주방 맵, 첫 직원 선택
- 속성·이동/작업 속도가 다른 슬라임 4종
- 좌클릭 단일 선택, `Q/W/E/R/Space` 그룹 선택, 선택 링
- 우클릭 속도 기반 유클리드 직선 이동과 설비 상호작용
- 버섯 자동 생성, 단일 불 슬라임 조리, 속성 거부, 재료 대기·자동 재개
- 조리 도구 상태·작업자·진행도, 버섯 구이 운반·제출
- 물 슬라임 선택 카드 SVG·탄성 애니메이션, 인게임 4방향 스프라이트
- 홈·일반 영업 음악, 남은 시간 30초 이하 러쉬 음악
- 순차 주문, 골드, 3분 라운드, D1 플레이 요약
- 신뢰 경계와 상태 전이를 검증하는 결정론 코어 테스트·CLI

## 제거된 범위

- 약초·물약·스크롤, 마법진, 이전 종류명과 스탯 프리셋
- 스크롤 작업대와 두 색 자원 제작 데이터
- 음성 입력, STT, Gemini 명령 해석, 음성 결과 UI, 호출명 선택
- 청력·집중력 스탯과 명령 접수 판정
- 음성 실험실과 음성 API

## 현재 제외·열린 질문

- 드래그/추가 선택, 이동 진형·충돌·장애물 회피, 작업 예약 큐
- 다른 설비의 속성 규칙, 카메라 조작, 상세 오브젝트 정보 화면
- 죽음을 발생시키는 규칙과 부활 시스템
- 주문 10초 간격 유입과 복수 주문 동시 표시
- 라운드 사이 업그레이드·성장 선택
