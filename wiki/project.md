# NAN 2026

## 공모전 목적

이 저장소는 **NAN 2026 (Next AI Network) Game × AI 해커톤** 참가·출품을
위한 프로젝트다. 프로젝트 문서와 외부 소개는 현재 게임의 실제 구현을 근거로 하되,
공식 사전 과제인 `AI를 활용한 게임 제작`의 맥락을 분명히 한다.

## 한 문장

플레이어가 속성이 다른 슬라임 4마리를 한 마리씩 골라 행동력을 나눠 쓰며
정해진 턴 안에 구운 감자 주문을 채우는 턴제 Phaser 3 펀테스트.

## 현재 플레이 흐름

```text
네 속성 슬라임을 모두 데리고 시작
→ 슬라임을 좌클릭해 고르고 상하좌우 표시가 뜬 칸으로 한 칸씩 이동
→ 재료 상자 옆에 서서 감자 집기
→ 도마 옆에 서서 감자를 올리고, 땅 슬라임이 행동력 2를 들여 썰기
→ 구운 감자를 집어 그릇 생성대에서 접시에 담기
→ 제출대 옆에 서서 제출하고, 더러워진 접시는 세척기에 넣어 물 슬라임이 세척
→ 할 일이 끝나면 턴 종료
```

- 이동과 행동은 모두 **행동력** 하나로 계산한다. 턴이 시작될 때 채워지고
  턴이 끝나면 남은 만큼 사라진다.
- 슬라임끼리 같은 칸에 설 수 없다. 이동 가능 표시가 점유된 칸을 빼므로
  자리 교환도 자연히 막힌다.
- 조리·세척·소각은 행동력이 모자라면 넣은 만큼만 진척도가 오르고 다음
  턴에 이어서 한다. 중단해도 진척도는 남는다.
- 유효하지 않은 상호작용은 행동력을 쓰지 않고 토스트로 이유를 알려 준다.
- 현재 소지품은 슬라임이 앞으로 든 것처럼 보여 준다. 등을 돌리면 몸 뒤로
  넘어가 위쪽만 보인다.

## 조작

- 슬라임 좌클릭(또는 하단 슬라임 버튼): 한 마리 선택. 다시 누르면 해제
- 선택하면 상하좌우 한 칸에 이동 가능 표시가 뜬다. 벽·설비 칸과 다른
  슬라임이 선 칸, 행동력이 없을 때는 표시가 뜨지 않는다
- 이동 가능 표시 좌클릭: 그 칸으로 한 칸 이동(행동력 1)
- 설비 좌클릭: 정보 패널을 열고, 고른 슬라임이 옆 칸에 서 있으면 사용한다
- 고른 슬라임으로 멀리 있는 설비를 누르면 선택을 풀지 않고 옆 칸에 서야 한다는
  거절 토스트와 설비 정보를 보여 준다
- 빈 바닥 좌클릭: 선택 해제
- `턴 종료` 버튼: 남은 행동력을 버리고 다음 턴으로 넘어간다
- `Esc`: 설정 창
- `Space`: 즉시 턴 종료
- `Z`: 마지막 성공 행동 한 번 되돌리기. 턴이 바뀌어도 유지하되 스테이지가
  끝나거나 다시 시작되면 사라진다
- 모든 슬라임이 행동력을 썼거나 쉬기로 하면 자동으로 다음 턴을 시작한다.
  `턴 종료` 버튼은 남은 행동력을 한꺼번에 버릴 때만 쓴다

한 번에 한 마리만 고른다. 내부 속성 ID는 물·불·번개·땅을 유지하고 화면 표시
이름은 대화 대본과 같이 퐁당이·이글이·번쩍이·푸름이를 쓴다. 속성을 가르는
수치는 턴당 행동력 하나뿐이다.

### 행동력

| 슬라임 | 턴당 행동력 |
|---|---:|
| 번개(전기) | 2 |
| 물·불·땅 | 1 |

| 행동 | 소모 |
|---|---:|
| 한 칸 이동 | 1 |
| 물건 집기·놓기·버리기·제출 | 1 |
| 도마 썰기 | 1 |
| 그릇 세척 | 1 |
| 소각 | 1 |
| 믹서기 물 채우기·가동 | 각 1 |

### 기구별 속성 제한

| 기구 | 행동 | 속성 |
|---|---|---|
속성은 **여러 개**일 수 있다. 목록에 든 속성이면 누구나 그 일을 한다.

| 기구 | 행동 | 속성 |
|---|---|---|
| 도마 | 썰기 | 레시피의 `workers`. 지금은 셋 다 [땅] |
| 화덕·튀김기 | 굽기·튀기기 | 레시피의 `workers`. 지금은 다 [불] |
| 믹서기 | 물 채우기 | `stationElements.wash`. 지금은 [물] |
| 믹서기 | 가동 | 레시피의 `workers`. 지금은 둘 다 [번개] |
| 세척대 | 세척 | `stationElements.wash`. 지금은 [물] |
| 소각기 | 소각 | `stationElements.burn`. 지금은 [불] |
| 그 외 전부 | 물건 집기·놓기 포함 | 제한 없음 |

### 맵 구성

기구는 **차지한 칸 아무 곳에나 붙어 서면** 쓸 수 있다. 지정 작업 위치는 없다.

| 기구 | 타일 | 칸 |
|---|---|---:|
| 감자·당근·양배추 상자 | `P` `R` `A` | 1 |
| 바나나·딸기·버섯 상자 | `B` `Y` `U` | 1 |
| 도마 | `C` | 1 |
| 화덕·튀김기·믹서기 | `O` `F` `M` | 1 |
| 소각기·그릇 상자·그릇 반납대·테이블 | `X` `D` `N` `T` | 1 |
| 음식 제출대 | `S` | 2 |
| 세척대 | `W` | 2 |

여러 칸 기구는 맞닿은 같은 글자를 한 대로 묶는다. 한 칸짜리는 붙여 놓아도
각각 다른 대다. 슬라임 자리는 속성별로 한 칸씩 맵에 찍는다.

## 구현 원칙

- Phaser 3, TypeScript, 데스크톱·모바일 웹 브라우저를 사용한다.
- 브라우저와 이미 설치된 기능을 우선하며 새 의존성을 추가하지 않는다.
- 규칙과 상태 전이는 렌더링에서 분리해 CLI와 테스트에서 실행한다.
- 같은 seed, 스쿼드, 조작, 경과 시간은 같은 결과를 만든다.
- 기능은 계획, 작업, 검증 순서로 진행한다.

## 현재 구현

- 홈 URL에서 문서를 새로 열 때 팀 로고를 도장처럼 찍고 공개 그림을 미리 받은
  뒤 홈을 연다. 홈 새로고침에는 다시 나오고 게임→홈 내부 이동과 `/game/`
  직접 진입에는 나오지 않는다.
  도장 효과음은 미리 받되 브라우저 자동재생 정책이 막으면 화면 진행을 막지 않는다
- 모드 선택 화면은 제공된 `mode-select-title.png` 제목 그림을 사용한다
- Pages CI는 코어 테스트·lint·빌드뿐 아니라 `app/*.tsx` 전체 TypeScript 검사도 통과해야 한다
- 새 `슬라임 레스토랑` 로고와 기존 책상·가마솟·거품·슬라임 배치의 홈 화면
- 홈 장식을 뷰포트 전체에 배치하고 게임 프레임을 화면 끝까지 채우는 반응형
  레이아웃. 세로로 긴 화면은 식당 목재 배경으로 남는 영역을 연결하며,
  휴대폰 가로 화면에 맞춰 HUD 레일과 정보 패널을 재배치하고 세로 화면에서는
  가로 회전 안내만 표시한다
- 게임 중 홈 이동은 상시 버튼 대신 설정 모달 안에서만 제공한다
- 홈·인게임 상단 소리 설정 탭. 왼쪽 스피커 그림이 켜기·끄기를 겸하고
  오른쪽이 음량이다. 음악과 효과음을 따로 조절해 저장한다. 스피커 아이콘은
  `raw/0.png`(음소거)·`raw/1.png`(켜짐)을 잘라 쓴다
- 손이 차서 지금 못 하는 지시를 받으면 가까운 빈 테이블에 먼저 내려놓고
  원래 작업을 이어서 한다
- 낱개 음식을 들고 그릇 생성대에 가면 빈 접시를 꺼내 그 자리에서 담는다
- 외곽 조리대와 중앙 작업 섬으로 구성된 14×8 주방 맵. 첫 판은 네 속성을
  모두 데리고 시작하며 고르는 화면은 없다
- 맵에는 코드로 덧그린 장식·광원 원·작업칸 점을 두지 않고 바닥·벽·실제
  설비만 상시 표시한다
- 게임 코어와 화면이 함께 읽는 단일 맵 데이터와 `127.0.0.1` 전용 맵
  에디터. `edit-map.sh`로 실행하며 설비·상호작용 칸·스폰을 검증한 뒤
  원자적으로 저장한다
- 설비는 `종류@열,행` 좌표 ID를 가지며 같은 종류를 여러 개 배치해도 보관물,
  작업자·진행도와 화재가 서로 섞이지 않는다. 작업 위치는 위→왼쪽→오른쪽→
  아래 순서로 자동 선택하고 에디터에서 설비 ID별로 고정할 수 있다
- `deploy.sh`로 현재 변경을 검증한 뒤 기존 Codex Sites 프로젝트에 자동 배포한다.
  원문인 `raw/`의 수정·미추적 파일은 배포 커밋에서 제외한다
- `main` 소스와 정적 게임 빌드는 GitHub Pages
  `https://run-the-pass.github.io/NAN2026/`로도 자동 배포한다. Pages에서는
  서버가 필요한 D1 플레이 기록만 비활성화한다. 게임의 뒤로가기는 Next가
  `basePath`를 한 번만 붙이도록 앱 루트 `/`로 이동한다
- 슬라임은 맵에 속성별로 찍어 둔 자리에서 시작한다. 같은 속성을 여러 마리
  데려오면 2호부터 그 자리에서 가까운 빈 바닥으로 밀려난다
- 턴당 행동력이 다른 슬라임 4종. 번개만 2고 나머지는 1이다
- 한 마리 선택과 선택 링, 인접 4칸 이동 표시, 하단 슬라임별 행동력 표시와
  `턴 종료` 버튼
- 첫 스테이지는 PDF식 점장 인사 뒤 땅 슬라임으로 양배추를 손질하고 테이블로
  물 슬라임에게 전달해 제출하면 종료 대사와 정산을 차례로 보여 주고 끝난다.
  2~4스테이지는 새 슬라임·턴 시계·조리 설비·믹서기를 여러 줄 대사로 소개하고,
  마지막 스테이지 승리 뒤에는 점장의 정직원 제안과 무한 모드 권유를 보여 준다
- 튜토리얼 화살표는 대상 바깥에 두고 `app/tutorial-arrow-layout.ts`의 좌표·회전·흔들림
  값으로 조절한다. 다른 슬라임에게 행동을 넘길 때는 지도 대신 하단 로스터 바깥에
  화살표를 둔다. 지도 화살표 좌표는 안내 단계가 시작될 때 한 번만 계산하고 같은
  `cue.id` 동안 고정한다. 대화창은 어두운 막·강조된 정보창보다 앞에 나온다
- 퐁당이 소개가 끝나면 새 턴을 시작해 푸름이와 퐁당이 모두 행동력을 받는다.
  한 명이 행동력을 다 쓰면 행동력이 남은 공개 슬라임을 자동 선택하고, 전원이
  행동했거나 쉬기로 하면 일반 게임과 같이 턴을 자동으로 넘긴다. 첫 행동력
  설명에서는 `Z` 되돌리기 버튼을 한 번 강조한다
- 튜토리얼에서 지목된 슬라임은 현재 화살표 목표에 가까워지는 이동과 지목된 설비
  상호작용만 받는다. 다른 공개 슬라임은 자유 이동할 수 있지만 현재 단계의 설비
  상호작용은 할 수 없다
- 행동 안내창은 데스크톱에서 게임판 밖 우측 정보 레일에 두고, 모바일 가로에서는
  현재 작업 슬라임과 설비를 피하도록 화자에 따라 지도 위·아래로 나눈다
- 최고 별을 `nan2026.progress.v2` 쿠키에 저장한다. 아르바이트 모드를 누르면
  튜토리얼 0과 1~3 스테이지 선택이 나오며, 직전 판을 깨야 다음 판이 열린다.
  잠긴 판은 숫자 대신 자물쇠를 표시하고 이어하기 팝업은 사용하지 않는다.
  스테이지 숫자와 클리어 문구는 제공된 그림을 쓰며, 튜토리얼은 나무 버튼 판
  전체를 녹색으로 구분한다. 모드 카드의 진행도는 노란 별 그림과 `현재 / 12`로
  표시한다
- 설정과 정산의 재도전은 현재 모드·스테이지를 초기 상태로 다시 연다. 승리한
  중간 스테이지 정산에는 다음 스테이지·재도전·나가기를 함께 표시한다
- 무한 모드는 마지막 아르바이트 스테이지 클리어 뒤 열린다. 네 슬라임과 40턴으로
  시작하고 주문 완료마다 3턴과 1점을 얻는다. 두 수치는 밸런스 편집기에서
  조정한다. 현재 모든 레시피를 시드 기반으로
  한 번씩 섞은 큐를 소진할 때마다 다시 채우며, 0턴에 승리 정산으로 끝나 완료
  음식 수를 최종 점수로 표시한다
- 다이얼로그의 음식·재료는 주황, 도구·설비는 파랑, 슬라임 이름은 초록으로
  표시한다
- 다이얼로그 본문은 한국어 단어를 중간에서 나누지 않고 문장 균형을 우선한다.
  시계 설명 화살표는 턴 시계 아래에서 위를 향하고, 정산 제목 그림은 종이의
  가로 중앙에 맞춘다. 정산 버튼의 키보드 포커스는 노란 빛 대신 갈색 외곽선이다
- 상하좌우 타일 이동과 슬라임 충돌. 벽·설비 칸과 점유된 칸은 이동 후보와
  경로에서 빠지며, 여러 칸 이동 애니메이션도 BFS 최단 경로의 타일 중심을
  순서대로 지난다
- 설비 옆 칸에 선 슬라임만 그 설비를 쓴다
- 재료 상자·도마·소각기의 한 타일 정사각형 표시와 60×60 타일 전체
  우클릭 상호작용 판정
- y좌표 기반 슬라임·설비 깊이 정렬, 설정 중 정지와 즉시 재개
- 재료 상자에는 용량과 턴 보충이 없고 언제든 같은 재료를 꺼낼 수 있다.
  감자·당근·양배추는 셋 다 도마에서 썰어
  구운 감자·썬 당근·썬 양배추가 된다. 땅 슬라임 전용이고 진척도는 턴을 넘긴다
- 스무디는 컵째 나가 그릇이 필요 없다(레시피의 `servedInDish: false`).
  회수할 때 그릇에 담기지 않고 손에 들리며, 제출해도 반납대로 갈 그릇이 없다
- 믹서기는 과일 → 물 → 가동 순서로만 진행한다. 넣은 과일은 뺄 수 없고, 물을
  먼저 채울 수도 없다. 물은 물 슬라임이, 가동은 번개 슬라임이 하며 각각
  상호작용 한 번이다. 바나나 스무디와 딸기 스무디가 나온다
- 화덕과 튀김기는 도마와 같은 규칙으로 돈다(`cooktopStations`). 재료를 올리고
  속성이 맞는 슬라임이 조리한 뒤 회수한다. 감자 튀김·버섯 튀김·버섯 구이가 있다
- 썬 당근과 썬 양배추는 접시 없이 테이블에서 먼저 샐러드로 합칠 수 있다.
  한 재료가 담긴 접시와 나머지 재료를 합치는 기존 방식도 되고, 제출할 때는
  다른 음식처럼 깨끗한 접시에 담겨 있어야 한다
- 제출한 그릇은 즉시 그릇 반납대에 더러운 채로 나타난다. 그릇 상자는
  자동으로 그릇을 만들지 않는다
- 세척대 그림은 오른쪽 싱크대에 더러운 그릇, 왼쪽 건조대에 깨끗한 그릇을
  한 장씩 대표로 표시한다. 설비 정보의 필요 슬라임 표시는 공용 판넬 그림을 쓴다
- 밸런스 수치는 JSON 세 개에 모여 있다. `game/balance.json`(행동력·행동
  비용·기구 담당 속성·무한 모드/그릇/소각기 수치·주문·랭크), `game/recipes.json`
  (레시피), `game/stages.json`(제한 턴·주문 목록·별 기준)이다. 코드가
  아니라 이 세 파일을 만진다. `npm run balance:edit`로 여는 로컬 편집기가
  세 파일을 함께 다루고, 저장 전에 게임과 같은 규칙으로 검증한다
- 음식 제출대와 세척대는 2칸을 한 대로 쓴다. 모든 기구는 붙은 어느 방향에서든
  사용할 수 있고 지정 작업 위치가 없다
- `raw/에셋`과 `raw/에셋3`의 그림을 투명 여백을 잘라 줄여 기구·재료·완성
  음식에 입혔다
- 도마 상태와 진행도 표시, 완성 음식은 낱개로 회수하되 제출은 깨끗한 접시만 가능
- 테이블 위 도마, 감자를 올린 재료 상자, 빈 접시 위에
  음식을 얹은 주문 카드
- 판 시작 "영업 시작", 남은 턴 10 이하 "마감 임박", 정산 "영업 종료"·"게임 오버"
  문구 이미지
- 공용 글자 버튼은 `raw/btn_1.png`를 투명 재단한 그림을 쓴다. 설정의 홈과
  턴 종료도 같은 버튼이며, 턴 종료 아래 보조 문구와 정산의 기록 저장 문구는 없다
- 인게임 슬라임은 각 초상화 SVG의 몸통을 직접 쓴다. 물은 초상화와 같은 물결
  경계·하단 수면층·하이라이트·외곽선을 유지하고, 물·번개·땅은 각 초상화
  비율의 둥근 눈과 입을 쓴다. 불은 큰 원의
  윗부분만 사선으로 조금 잘라낸 눈과 큰 입을 쓰며
  눈을 감았을 때도 양쪽 눈이 같은 방향으로 기울어진다.
  슬라임 선택 표시는
  몸통 바닥 폭에 맞춘 속성색 가로 타원이다
- 작업량은 정수 행동력이다. 남은 행동력만큼만 진척도가 오르고 모자라면
  다음 턴에 이어서 한다. 조리·세척·소각이 모두 이 규칙을 탄다
- 유효하지 않은 상호작용은 행동력을 쓰지 않고 화면 아래 토스트로 이유를
  알려 준다
- 설비 이름 외에 내부 키·좌표는 화면에 표시하지 않는다
- 설비 이름은 상시 표시하지 않는다. 상태만 타일 위에 남긴다
- 홈은 문서 스크롤과 고무줄 튕김을 막고, 설정 창이 홈 메뉴 위로 열린다.
  왼쪽 테이블은 창 종횡비와 무관하게 화면 바닥에 붙인다
- 네 슬라임 선택 카드의 몸통 크기·탄성 주기 정렬. 번개·땅·불 원본 SVG의
  장식을 보존하고 인게임 숨쉬기·걷기·작업 모션과 좌우 반전을 적용한다
- 고유 그릇 5개 생성, 깨끗한 접시만 제출, 사용 접시 오염,
  물 슬라임 세척과 재사용 순환
- 소각기는 설비별로 최대 5개까지 쓰레기를 버리고, 불 슬라임의 소각 작업으로
  비운다. 가득 찼을 때 불 슬라임이 오면 물건을 들고 있어도 소각부터 하며,
  거절할 때는 가득 참·소각할 것 없음을 구분해 알려 준다
- 그릇·재료를 한 칸 보관하고 감자와 빈 접시를 순서와 무관하게 합치는
  테이블, 땅 슬라임 그릇 2개 운반, 생성대·세척기·테이블 상태 표시
- 홈·일반 영업 음악, 남은 턴 10 이하 러쉬 음악, 패배 결과 음악
- UI·라운드·주문·조리·설거지·운반·화재·슬라임 선택과 이동 효과음
- 스테이지별 레시피 목록을 순서대로 소비하는 주문 시스템. 동시에 2건을
  노출하고 다음 레시피 2개를 주문 카드 옆에 작게 미리 보여 준다
- 스테이지마다 별 기준 셋(`stars`)이 있다. 첫 값이 통과 기준이고, 처리한
  주문 수가 각 지점을 넘을 때마다 별이 하나씩 오른다. 기준만 채우면
  별 1개, 2건 더 처리하면 별 2개, 3건이면 별 3개
- 상단 전용 영역의 주문 카드 2장과 턴 HUD. 시간 게이지는 없다
- 턴 HUD의 시계는 전체 제한 턴 중 지난 턴을 회색, 남은 턴을 흰 부채꼴로
  표시하고 턴이 바뀔 때 바늘과 함께 움직인다
- 슬라임 한 마리를 선택하면 우측 상세 패널을 즉시 열며 남은 행동력을 보여 준다.
  행동력이 0이어도 직접 선택해 상세 정보를 볼 수 있고, 행동은 할 수 없다
- 맵을 덮지 않는 우측 전용 레일의 슬라임·설비 정보 패널과 게임을 멈추는
  설비 상세 도움말. Phaser 맵은 남은 영역의 왼쪽에 정렬한다
- 캐릭터 선택, 상단 주문·HUD, 정보·설정과 게임 오버 화면은 검보라 웹 패널
  대신 식당의 목재·철제·종이 재질과 각진 판형을 사용한다
- 인스턴스 ID 기반 슬라임. 같은 속성을 여러 마리 데려올 수 있고 속성
  키는 그 속성의 모든 마리를 고른다
- 원본 번개·땅·불 슬라임의 머리 장식을 제외한 몸통 크기를 물 슬라임과
  맞추고, 물 슬라임 기준의 눈·입 간격, 이동 방향별 얼굴·등 표시, 정지·이동 중
  깜빡임을 적용한다. 불 눈은 공통 눈보다 20% 크고 원의 윗부분을 사선으로 자른 형태다
- `1-1`~`1-3` 기본 스테이지 루프와 턴 제한, 스테이지 HUD, 주문 성공·남은 턴
  정산, 랭크 별 표시, 다음 스테이지·재시작·타이틀 이동
- 정산의 랭크는 제공된 회색·노란색 별 그림으로 표시한다
- 스테이지 선택에서는 완료 기록이 있는 버튼 아래에 최고 기록만큼 노란 별을
  표시하고, 미클리어·잠금 버튼에는 표시하지 않는다
- 판 시작 전과 스테이지 정산 뒤 표시되는 전환 정보 화면. 실제 14×8
  주방 맵, TIP 2개, 3×2 음식 슬롯과 공용 레시피 기반 제작 흐름을 표시하며
  화면이 열린 동안 게임 상태와 타이머를 멈춘다
- 주문 실수는 진행도에 영향을 주지 않고, 죽음·화재 감점·점수·랭킹과 함께 정산에서 제외
- 첫 화면은 사용자 입력 뒤 도장 효과음과 로고 연출을 보이며, 그 동안 공개 그림·글꼴·게임
  코드를 미리 받는다. 홈 문서를 새로 열 때마다 보이고, 도장 중 종이 배경은 움직이지 않는다
- 홈 크레딧 창은 슬라임 노동조합 로고·팀명, 이정민·윤정호, Suno 음악 제작과
  ElevenLabs 효과음 제작을 표시하며, 두 제작사 이름과 링크 아이콘은 각 공식
  사이트로 연결한다
- 튜토리얼에서 퐁당이는 등장 직후 접시를 먼저 집고, 그 뒤 푸름이가 음식을
  테이블로 전달한다. 짧은 안내는 우측 정보 창이 아닌 하단 HUD에 표시한다
- 게임 UI의 글자 선택과 이미지 기본 드래그를 막고, 지도 화살표는 Phaser
  캔버스보다 앞에 표시한다
- 이동·상호작용 하이라이트는 테이블 상판보다 앞, 상판 위 도마·믹서기·음식보다
  뒤에 표시한다. 클릭한 슬라임·설비 이름표는 맵 오브젝트와 하이라이트보다 앞에
  표시하며, 정산 버튼은 자동 포커스 없이 같은 기본 상태로 연다. 이동 가능 칸은
  현재 선택한 슬라임의 속성색으로 표시한다. 현재 행동력으로 인접 칸까지 갈 수
  있는 설비도 같은 속성색의 반투명 면으로 채우며, 현재 자리에서 사용할 수 있으면
  기본 화살표 옆 번개, 사용할 수 없으면 기본 화살표 옆 X 커서를 쓴다. 설비
  클릭 상호작용 직후에는 바뀐 상태로 가능 여부를 다시 계산해 커서를 즉시 바꾼다
- 호버·키보드 포커스 설명과 행동 거절 토스트는 `base2.png`를 9분할해 글자 길이에
  맞춰 늘린다. 특징 설명은 우측 특징 칸을 기준으로 패널 안쪽에 펼쳐 화면 밖으로
  잘리지 않게 한다. 행동 거절 토스트는 실패한 설비를 클릭한 위치 가까이에 띄운다
- 골드, 턴 제한 라운드, D1 플레이 요약
- 신뢰 경계와 상태 전이를 검증하는 결정론 코어 테스트·CLI
- 도마·믹서기에서 레시피가 없는 물건(예: 버섯)을 들고 상호작용하면 그
  물건 이름을 짚어 알려 준다("버섯을 먼저 내려놓아야 합니다")
- 설비 재고 게이지는 칸으로 나눠 그린다. 인게임 캔버스 표시와 정보 패널의
  `stat-gauge`(행동력과 같은 모양, 색만 초록·다 찼을 때 주황) 모두 해당한다.
  정보 패널의 용량 줄은 내용 너비로 가운데 모으고 세척대도 현재/최대 그릇 수를 표시한다
- 들고 있는 것은 슬라임 머리 위 "?" 왼쪽에 실제 게임 그림으로 보여 준다.
  그릇은 접시(또는 더러운 접시) 그림 위에 담긴 음식 그림을 얹는다
- `Space`는 턴 종료, `Z`는 마지막 성공 행동 되돌리기다. 되돌리기는 위치·방향·
  소지품·행동력·설비·주문·남은 턴을 직전 상태로 함께 복구한다
- 설비 정보 패널·자세히 보기의 아이콘은 이모지 대신 실제 설비·재료 그림을
  쓴다(상자류는 담긴 재료, 나머지는 설비 그림)

주문의 미확정 규칙은 `game/core.ts`의 `orderConfig`, 행동력 수치는
`actionPointsPerTurn`·`actionCost`, 속성 제한은 `stationElements`로 분리했다.
턴제 전환 범위와 확정된 결정은 [턴제 전환 계획](plan-turn-based.md)에 있다.
