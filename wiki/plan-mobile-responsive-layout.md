# 모바일 반응형 레이아웃 계획

## 범위

- 기존 Phaser 게임과 DOM HUD를 그대로 쓰고 휴대폰 가로 화면에 맞춰 레일
  크기와 UI 배치를 조정한다.
- 휴대폰 가로 화면에서는 주문 영역을 줄이고 정보 패널을 지도 위 오버레이로
  띄워 실제 플레이 영역을 확보한다.
- 휴대폰 세로 화면에서는 플레이 화면 대신 가로 회전 안내를 표시한다.
- 터치로 누르는 주요 버튼은 최소 44px 크기를 유지한다.

## 하지 않는 것

- 모바일 전용 게임 화면이나 별도 조작 체계를 만들지 않는다.
- 기기의 화면 방향을 코드로 강제 전환하지 않는다.
- 게임 규칙, 맵 크기, 튜토리얼 진행과 저장 형식은 바꾸지 않는다.

## 완료 조건

- 390×844 세로에서는 가로 회전 안내만 보이고 게임 입력이 막힌다.
- 844×390 가로에서 문서 스크롤 없이 지도, 주문, 남은 턴, 슬라임 선택과
  턴 종료 버튼을 사용할 수 있다.
- 선택 정보, 대화, 설정과 정산 창이 화면 안에서 읽고 닫을 수 있다.
- 1280×720 데스크톱 레이아웃에 회귀가 없다.
- 테스트, 타입검사, 린트와 GitHub Pages 빌드가 통과한다.
