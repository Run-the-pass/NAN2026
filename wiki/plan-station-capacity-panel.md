# 설비 용량 표시 보정 계획

## 범위

- 세척대 정보 패널에 현재 그릇 수와 최대 용량을 표시한다.
- 재료 상자·그릇 상자·반납대·소각기·세척대의 용량 표시를 내용 크기만큼만 배치한다.
- 새 컴포넌트나 설정은 추가하지 않고 기존 `StationStock`과 `dishConfig.washerCapacity`를 쓴다.

## 완료 조건

- 빈 세척대를 눌러도 `세척 중인 그릇 0 / 3`이 보인다.
- 용량 줄의 이름·칸·숫자가 패널 전체 폭으로 늘어지지 않고 가운데에 모인다.
- 기존 설비의 용량과 세척대 실제 그릇 수가 일치한다.
- 테스트, lint, 빌드와 브라우저 화면 확인을 통과한다.

## 구현·검증 결과

- `stationStock`의 공용 분기에 세척대를 추가해 빈 상태도 `세척 중인 그릇 0 / 3`으로 표시한다.
- 용량 줄을 내용 너비로 가운데 정렬하고, 과거 행동력 UI가 칸을 20px로 키우던 낡은 CSS를 삭제했다.
- 브라우저에서 4칸 게이지가 95px에서 57px로 줄어든 것을 확인했다.
- 테스트 55/55, lint, 빌드: `PASS`.
