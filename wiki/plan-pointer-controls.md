# 마우스·키보드 조작 전환 계획

## 구현 범위

- 좌클릭으로 슬라임 한 마리를 선택하고 빈 바닥을 좌클릭하면 해제한다.
- `Q/W/E/R`로 물/불/번개/땅 슬라임, `Space`로 전체를 선택한다.
- 선택된 슬라임에 표시를 남기고, 바닥 우클릭은 속도 기반 이동, 설비 우클릭은 이동 후 집기·놓기를 수행한다.
- 재료나 가공품이 없는 생성·가공 설비에서는 재고가 생길 때까지 대기한다.
- 새 조작 명령은 기존 작업을 교체한다. 이 정책은 로그로 보여 준다.
- 게임 화면의 음성 입력·결과·청력 범위·집중력 제한과 음성 실험실·API를 제거한다.

## 구현하지 않는 범위

- 미정인 드래그/추가 선택, 배치 진형, 작업 예약 큐, 설비별 동시 작업 인원, 카메라 조작은 추가하지 않는다.
- 죽음을 유발하는 규칙이 없으므로 죽음·부활 시스템은 이번 범위에 포함하지 않는다.
- 기존 D1 테이블과 마이그레이션은 배포 데이터 손실을 피하기 위해 삭제하지 않는다.

## 완료 조건

- 단일·속성별·전체 선택이 화면에 구분되고, 빈 바닥 클릭으로 해제된다.
- 걸을 수 있는 바닥 우클릭은 선택된 슬라임을 이동시키고, 벽 우클릭은 상태를 바꾸지 않는다.
- 설비 우클릭은 선택된 슬라임을 작업 타일로 이동시킨 뒤 현재 소지품과 설비 재고에 맞는 상호작용을 한다.
- 필요한 재고가 없는 생성·가공 설비에서 대기하다가 재고가 생기면 자동으로 집는다.
- 음성과 관련된 화면 요소·라우트·게임 판정이 실행 경로에 남지 않는다.
- 코어 테스트, 린트, 프로덕션 빌드가 통과한다.
