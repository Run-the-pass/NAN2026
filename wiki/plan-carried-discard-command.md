# 현재 소지품 목적지 변경 명령 계획

## 결정

- `"날쌘아, 그거 버려"`, `"그거 테이블로 가져가"`,
  `"들고 있는 거 제출해"`, `"가지고 있는 거 양조기에 넣어"`는 지목한
  슬라임이 현재 든 물품을 뜻한다.
- 기존 운반 목적지를 취소하고 말한 목적지의 작업 타일로 이동한 뒤 기존
  투입 규칙을 적용한다. `테이블`은 마법 테이블의 약칭이다.
- `"붉은 물약 버려"`처럼 물품을 직접 말하는 기존 명령은 재고에서 해당
  물품을 가져와 버리는 현재 동작을 유지한다.

## 구현 범위

1. 로컬 사전에서 대상 호칭, 현재 소지품 지시어와 양조기·마법 테이블·
   제출대·쓰레기통 목적지를 함께 감지한다.
2. 게임 코어가 현재 소지품과 명령 수신 거리, 진행 상태를 검증한다.
3. 소지품이 있고 그 물품에 허용된 목적지이면 현재 작업을
   `그 물품 → 말한 목적지` 운반으로 바꾸고, 대기열은 유지한다.
4. 소지품이 없거나 듣지 못하면 상태를 임의로 만들지 않고 이유를 남긴다.
5. Gemini 텍스트 재분석은 사용하지 않는다.
6. 음성 실험실의 해야 할 일에 네 목적지와 `그거`, `들고 있는 거`,
   `가지고 있는 거` 조합을 각각 추가한다. 기존 기대값·문장 저장 필드를
   재사용하며 별도 테이블은 만들지 않는다.

## 완료 조건

- 세 지시어와 네 목적지 조합이 올바른 슬라임과 목적지를 고른다.
- 소지품이 쓰레기통에 도착하기 전까지 유지되고, 도착 뒤 사라진다.
- 원래 목적지에는 결과물이 생기지 않는다.
- 약초를 `그거 테이블로 가져가`로 전환하면 마법 테이블 도착 뒤 같은
  색상의 스크롤이 생긴다.
- 현재 물품에 허용되지 않는 목적지는 새 작업을 만들지 않는다.
- 소지품이 없는 슬라임은 새 물품을 가져오지 않는다.
- 음성 실험실에서 열두 조합을 각각 선택·발화·저장할 수 있고, 현재
  소지품 목적지 변경으로 인식되면 대상·물품·목적지가 모두 일치한 것으로
  표시된다.
- 같은 상태와 입력은 같은 결과를 만들며 테스트와 빌드를 통과한다.
