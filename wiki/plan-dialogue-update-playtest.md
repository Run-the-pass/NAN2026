# 업데이트 다이얼로그·플레이테스트 계획

## 구현 범위

- 1스테이지 도입과 행동 안내를 PDF 2~32쪽 순서에 맞춘다.
- 푸름이의 이동·양배추 집기·도마 놓기·썰기를 각각 현재 상태에 맞춰 안내한다.
- 양배추를 썬 뒤 점장과 퐁당이의 등장 대사, 접시 합치기, 제출 안내를 보여 준다.
- 2~4스테이지 시작에 PDF의 여러 줄 대사를 넣고, 새로 소개하는 슬라임은
  대화창에 함께 표시한다.
- 4스테이지 클리어 뒤 PDF 51~53쪽의 마무리 대사를 보여 준 다음 정산한다.
- 실제 브라우저 플레이 결과를 별도 플레이 흐름 보고서로 남긴다.

## 구현하지 않는 범위

- PDF 30~31쪽의 같은 제출 문장을 두 번 반복하지 않는다.
- 아직 규칙이 없는 무한 모드 자체는 구현하지 않는다. 기존 해금 상태만 유지한다.
- PDF에 없는 자동 이동·자동 조리·새로운 확인 버튼은 추가하지 않는다.
- 함께 진행 중인 세척대 용량·레시피·스테이지 밸런스 변경은 수정하지 않는다.

## 완료 조건

- 튜토리얼이 `주문 확인 → 푸름이 → 양배추 손질 → 퐁당이와 접시 → 제출 →
  종료 대사 → 정산` 순서로 막힘 없이 끝난다.
- 2~4스테이지 시작 대사가 PDF 순서와 내용으로 표시된다.
- 마지막 스테이지 승리 대사 뒤 정산과 모드 선택이 정상 동작한다.
- 대사 대상, 화살표, 하이라이트, 초상, 이름표가 실제 화면에서 어긋나지 않는다.
- 코어 테스트·린트·빌드가 통과하고 브라우저 콘솔에 새 오류가 없다.
- 플레이 흐름 보고서에 단계별 결과와 발견한 문제·수정·최종 판정을 기록한다.

## 검증 결과

- **PASS** — 튜토리얼 전체와 2스테이지 시작까지 브라우저에서 직접 플레이했다.
- 행동 설명이 자동 턴에 묻히던 문제, 행동 화살표 누락·좌표 밀림, 종료 전
  이글이·번쩍이 선공개, 화살표 이동축을 수정했다.
- 테스트 54/54, lint, 프로덕션 빌드를 통과했다.
- 상세 결과는 [플레이 흐름 보고서](playtest-dialogue-flow-2026-08-09.md)에 있다.
