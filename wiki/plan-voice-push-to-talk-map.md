# 음성 사전·푸시투토크·공방 맵 보정 계획

## 문제와 근거

- 현재 로컬 사전은 `쫑긋`의 유사 발음과 `약초`의 일부 유사 발음을
  처리하지만, STT 결과 `좀 끄자`, `양초`는 처리하지 않는다.
- 현재 게임은 라운드가 시작되면 상시 STT와 음량 측정을 시작한다.
  사용자의 최신 지시는 스페이스바를 누르는 동안만 마이크를 켜는
  푸시투토크다.
- 공방은 16×10 고정 타일·설비 6종·작업 타일 규칙을 이미 만족한다.
  따라서 경로와 게임 규칙은 바꾸지 않고, 설비 구분과 공방 분위기를
  더 읽기 쉽게 보정한다.

## 구현 범위

1. `game/phrase.ts`의 기존 별칭 사전에 `좀 끄자`→쫑긋, `양초`→약초를
   추가하고, 해당 문장이 로컬 매칭으로 올바른 명령을 만드는 회귀 테스트를
   추가한다. Gemini allowlist에는 기존처럼 같은 슬라임 별칭을 전달한다.
2. 게임 시작 시 마이크 권한·STT·음량 측정을 시작하지 않는다. 포커스가
   입력 요소에 있지 않을 때 스페이스바를 누르면 녹음을 시작하고, 떼면
   정확히 한 번 종료·해석한다. 키 반복과 브라우저 스크롤을 막고, 기존
   마이크 버튼도 같은 시작/종료 경로를 사용한다.
3. `app/Game.tsx`의 Phaser 드로잉만 보정한다. 현재 타일 좌표, 충돌,
   설비·작업 위치는 유지하고, 벽·바닥 대비, 설비별 작업 구역, 비상호작용
   장식(선반·상자·조명)을 추가해 공방의 용도와 동선을 더 명확하게 한다.

## 구현하지 않을 범위

- 새 맵, 설비·자원·레시피, 타일 좌표나 BFS 규칙 변경
- 외부 STT 사전 또는 새 의존성
- 음성 명령의 의미를 결정하는 Gemini 규칙 변경

## 완료 조건

- `좀 끄자, 붉은 양초를 양조기에 넣어`가 쫑긋의 붉은 약초→양조기
  명령으로 로컬 매칭된다.
- 라운드 시작만으로는 마이크 권한 요청이나 청취가 시작되지 않는다.
  스페이스바 누름부터 뗌까지 한 발화만 전송되며, 입력창에서는 동작하지
  않고 페이지도 스크롤되지 않는다.
- 기존 16×10 맵의 설비·작업 타일·경로 테스트를 유지하며, 렌더링에서
  설비와 작업 위치가 더 쉽게 구분된다.
- 관련 테스트, lint, 프로덕션 빌드가 통과한다.
