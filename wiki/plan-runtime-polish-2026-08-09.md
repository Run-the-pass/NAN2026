# 로딩·턴·튜토리얼 안정화 계획

## 범위

- 첫 스플래시에서 공개 그림·글꼴과 게임 코드까지 받고, 같은 탭에서는 한 번만
  보여 준다. 스탬프 중 종이 배경은 움직이지 않는다.
- 공개된 슬라임 중 행동력이 남은 마리가 있으면 자동으로 턴을 넘기지 않는다.
- 행동력이 없는 슬라임 때문에 설비가 빨간색으로 표시되지 않게 한다.
- `마감 임박`을 다른 배너·대사가 끝난 뒤 한 번 보장해 표시한다.
- 정산의 주문 실수를 남은 턴으로 바꾸고 새 감자구이 그림을 적용한다.
- 튜토리얼에서는 현재 안내 대상과 가까워지는 이동·지목된 설비 상호작용만
  허용하고, 다른 선택은 안내 문구로 막는다.
- 서브 에이전트가 튜토리얼을 직접 플레이해 화살표 겹침과 동선 방해를 검수한다.
- 지도 화살표 좌표는 안내 단계가 시작될 때 한 번만 계산하고, 같은 `cue.id`
  동안 슬라임이나 상태가 움직여도 다시 계산하지 않는다.

## 제외 범위

- 일반 스테이지의 이동·상호작용 자유도는 바꾸지 않는다.
- 새 로딩 화면, 라우터, 오디오 계층이나 외부 의존성은 추가하지 않는다.

## 완료 조건

- 첫 스플래시 뒤 게임 화면에서 그림·게임 코드 로딩 문구가 별도로 보이지 않는다.
- 홈으로 돌아와도 같은 탭에서는 스플래시가 다시 나오지 않는다.
- 튜토리얼에서 푸름이·퐁당이 중 한 마리의 행동력이 남으면 턴 수가 줄지 않는다.
- 행동력 0인 불 슬라임 옆 화로가 빨갛게 표시되지 않는다.
- 마감 임박 배너, 남은 턴 정산, 새 감자구이 그림이 화면에 표시된다.
- 튜토리얼 이탈 이동·설비 클릭은 행동력을 쓰지 않고 현재 목표를 다시 안내한다.
- 같은 안내 단계에서 이동해도 화살표의 `left`·`top`·회전 값이 유지되고,
  다음 안내 단계에서만 새 좌표로 바뀐다.
- 테스트, typecheck, lint, Pages 빌드와 직접 브라우저 플레이를 통과한다.

## 결과

- `PASS`: 턴 전환과 화로 테두리, 마감 배너, 정산, 감자구이, 로딩과 재방문을 보정했다.
- `PASS`: 튜토리얼 목표에 가까워지는 이동과 지목된 상호작용만 허용하고, 이탈은 토스트로 막았다.
- `PASS`: 서브 에이전트가 1280×720에서 전체 플레이한 결과를 반영해 화살표를 44px로 줄이고
  선택·그릇 상자·테이블·제출대는 외곽으로, `USE_*`는 하단 로스터 바깥으로 옮겼다.
- `PASS`: 같은 `cue.id`의 화살표 좌표는 최초 계산값을 유지하고 다음 안내 단계에서만
  새 좌표를 계산한다.
