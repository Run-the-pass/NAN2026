# 웹판 모바일 UI·버그 보정

사용자가 웹판 수정을 명시했으므로 이번 요청 범위에서 웹판 동결을 해제한다.

## 범위

- 기존 아트를 유지하며 낮은 가로 화면의 레이아웃 조건을 하나로 정리한다.
- 노치·브라우저 주소창을 고려하고 주문·지도·턴 조작 영역을 분리한다.
- 정보 패널을 닫을 수 있게 하고 작은 화면에서도 설명과 설정·정산 내용을 읽게 한다.
- 세로로 잡아도 게임 화면을 가로로 회전해 표시한다. 회전 안내는 없애고 설정·대사 중 게임 입력을 막는다.
- 검토 중 확인된 터치 좌표·재시작·키보드 입력 문제를 수정하고 회귀 검증한다.

## 제외

Unity, 게임 밸런스·새 콘텐츠, 세로 전용 맵, 신규 UI 의존성은 추가하지 않는다.

## 완료 조건

- 667×375, 844×390, 932×430, 1024×768, 1280×720 기준 레이아웃을 검토한다.
- 가로에서 지도·주문·턴 버튼이 겹치지 않고 주요 버튼을 최소 44px로 누를 수 있다.
- 세로에서는 게임을 90도 돌려 표시하고 터치 좌표도 보정한다. 방향을 바꿔도 진행을 유지한다.
- 정보창을 닫아도 슬라임 선택을 유지하며 설명·설정·정산은 화면 안에서 접근 가능하다.
- 설정·대사 중 턴 종료와 선택이 상태를 바꾸지 않고 재도전이 깨끗이 초기화된다.
- 코어 테스트·타입검사·린트·Pages 빌드와 실제 브라우저 조작 결과를 기록한다.

## 검증 결과 — PASS (2026-09-08)

- 62개 자동 테스트, 앱 타입검사, lint, vinext 빌드와 GitHub Pages 정적 빌드 통과.
- 667×375, 844×390, 932×430, 1024×768, 1280×720 브라우저 레이아웃 검토. 375×667·390×844에서 가로 회전 표시, 홈·크레딧·설정과 게임 선택·이동을 추가 확인.
- 회전 전후 슬라임 위치·행동력·턴 유지와 다시 입력 가능한 상태 확인. Phaser 히트 테스트 이전에 좌표를 역변환하며 회귀 테스트로 모서리·중심을 확인한다.
- 이전 Chrome 터치 에뮬레이션으로 이동·원거리 거절 토스트 확인. 최종 회전 검증은 내장 브라우저 포인터로 수행했다(내장 브라우저는 CDP touch dispatch 미지원). 실제 iOS·Android 기기 검증은 수행하지 않았다.
- 튜토리얼 도입→양배추 손질→접시 회수→수동 턴 종료→되돌리기와 재도전 초기화 확인. 설정 키보드 포커스 유지·대사 일시정지, 일반 스테이지 18턴 종료→정산→재도전 확인.
- 수정 원인: 중복 모바일 CSS, 대사 영역 변경 시 Phaser 부모 크기 미갱신, TouchEvent에 없는 clientX/Y 사용, 튜토리얼 종료 허용 큐까지 막던 조건, 설정·대사 뒤 입력과 재도전 잔여 상태.
- Pages 빌드는 기존 .next 캐시에서 내부 오류가 발생했으나 캐시를 저장소 밖으로 보관하고 깨끗하게 빌드해 통과했다. vinext의 기존 500 kB 번들 경고는 남아 있다.
- 공개 배포는 아직 실행하지 않았다.
