# 첫 주문 튜토리얼 계획

## 구현 범위

- PDF의 점장 인사와 주문·땅 슬라임·상세 정보 지목 연출을 시작 대사에 반영한다.
- 완성한 양배추를 테이블에 놓고, 물 슬라임이 그릇과 합쳐 제출하도록 안내한다.
- 물 슬라임은 1스테이지 튜토리얼에서만 그릇 상자 앞에 배치한다.
- 양배추 한 접시를 제출하면 끝맺음 한 줄을 보여 주고 튜토리얼을 끝낸다.
- 다음 스테이지부터는 시작 대사 한 줄만 보여 준다.
- 목표 설비·슬라임·턴 종료 버튼을 강조하고, 같은 단계에 머물면 안내가 다시 움직인다.

## 구현하지 않는 범위

- 실제 게임 규칙을 우회하는 자동 이동·아이템 생성
- 카메라 확대·이동 때문에 조작 좌표가 바뀌는 연출
- 2·3스테이지의 신규 기구별 강제 튜토리얼

## 완료 조건

- 첫 주문이 땅 슬라임 → 테이블 → 물 슬라임 → 그릇 → 제출 순서로 안내된다.
- 첫 양배추 주문을 제출하면 튜토리얼 완료 대사가 한 줄 표시된다.
- 완료 대사 뒤 일반 스테이지와 같은 정산 창과 다음 스테이지 버튼이 표시된다.
- 안내 대상의 하이라이트·화살표와 정체 시 재강조가 보인다.
- 튜토리얼 상태 테스트, 전체 코어 테스트와 프로덕션 빌드가 통과한다.

## 검증 결과

- **PASS** — 문자 화살표 대신 기존 `raw/pointer-arrow.png`를 사용한다.
- 주문표와 상세 정보 창은 어두운 막보다 앞에 표시하고, 캔버스의 땅 슬라임은
  해당 위치만 밝히는 방식으로 실제 대상을 드러낸다.
- 행동 단계의 별도 토스트형 대화를 제거하고 기획서와 같은 하단 대화 상자로
  통일했다. 확인 버튼 없이 실제 행동을 하면 다음 안내로 넘어간다.
- 점장은 홈의 초록 슬라임을 사용하고, 주문 화살표는 두 주문서 사이 아래에서
  위를 가리키며 모든 화살표가 자신이 향한 방향으로 왕복한다.
- 점장 초상은 홈 연출과 같은 숨쉬기 움직임을 쓰고, 이름표는 초상과 겹치지
  않으면서 대화 상자에 맞닿게 배치한다.
- 푸름이 화살표는 왼쪽을 향해 같은 방향으로 흔들고, 퐁당이 첫 안내에서 물
  슬라임의 역할과 그릇 상자에서 깨끗한 그릇을 집는 행동을 함께 설명한다.
- 첫 주문은 푸름이 손질 → 테이블 전달 → 퐁당이 그릇 → 제출까지 안내한다.
- 물 슬라임은 그릇 상자 앞에서 공개되며 일반 스테이지 시작 위치는 유지한다.
- 모든 스테이지의 그릇 상자는 깨끗한 그릇 5개로 시작한다.
- 테스트 52/52, lint, 맵·밸런스 검증, 프로덕션 빌드를 통과했다. 주문표·땅
  슬라임·상세 정보 창 강조와 첫 행동 안내를 브라우저에서 확인했다.
- 다음 주문의 부모 레이어를 앞으로 올려 실제 미리보기만 밝게 보이게 하고,
  화살표를 카드 바로 아래에 맞췄다. 푸름이 화살표도 몸 중심에 맞췄다.
- 물 슬라임 등장 뒤에는 현재 안내 대상이 자동 선택되며, 첫 제출 뒤 완료 대사 →
  정산 → 다음 스테이지 시작 대사 순서로 직접 플레이해 확인했다.
