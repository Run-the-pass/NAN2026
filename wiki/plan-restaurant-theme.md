# 식당 테마 전환 계획

## 구현 범위

- 슬라임 코드 ID와 UI 이름을 물·불·번개·땅으로 교체하고 식당 역할에 맞는 새 스탯을 정의한다.
- 활성 아이템을 버섯·버섯 구이, 활성 설비를 재료 상자·조리 도구·음식 제출대·쓰레기 처리 공간으로 축소한다.
- 공방·마법진·약초·물약·스크롤 표현을 홈, 게임 UI, 로그, 현재 코드 데이터에서 제거한다.
- 기존 클릭 이동·복수 상호작용·불 슬라임 조리·제한 시간·진행도·제출 흐름은 유지한다.
- 새 물 슬라임 SVG를 선택 화면·상태 카드·게임 스프라이트에 사용한다.
- 홈 음악, 일반 라운드 음악, 30초 이하 마감 음악을 브라우저 기본 오디오로 재생한다.

## 구현하지 않는 범위

- 추가 요리와 전자식 조리기구, 설거지, 화재·소화, 발전기
- 네 속성의 모든 역할 구현, 다중 그릇 운반, 신규 주방 아트 제작
- 기존 D1 플레이 기록 스키마의 역사적 필드 이름 변경

## 완료 조건

- 신규 UI·현재 코어 데이터·로그에 이전 슬라임 종류명과 공방 전용 아이템·설비가 노출되지 않는다.
- 물·불·번개·땅 슬라임을 Q/W/E/R로 선택할 수 있고 불 슬라임만 버섯을 조리한다.
- 버섯 상자부터 버섯 구이 제출까지 기존 상호작용 흐름이 동작한다.
- 물 슬라임 SVG가 화면에 표시되고 세 음악 파일이 해당 화면·시간대에 연결된다.
- 결정론 테스트, 린트, 프로덕션 빌드와 브라우저 실제 플레이가 통과한다.
