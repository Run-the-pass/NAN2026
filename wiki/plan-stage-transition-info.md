# 스테이지 전환 정보 화면 계획

## 범위

- 기존 슬라임 선택 뒤 첫 스테이지 정보 화면을 한 번 표시한다.
- 스테이지 클리어 정산 뒤 다음 스테이지 정보 화면을 표시한다.
- 상단 제목, 좌측 16×10 정적 맵 미리보기, 우측 3×2 음식 슬롯과 호버·
  키보드 상세 정보, TIP 최대 2개, 하단 다음 버튼을 구현한다.
- 기존 맵·설비·음식·레시피 ID를 공용 데이터로 읽고 설정 제한을 검증한다.
- 정보 화면과 설정이 열린 동안 코어 타이머와 Phaser 모션을 멈춘다.

## 구현하지 않는 범위

- 아직 없는 슬라임 영입 화면과 가짜 로딩 화면
- 새 음식·레시피·맵·게임 규칙
- 별도 도구 카드, 점수, 랭킹, 인게임 상세 팝업

## 결정

- 정보 화면은 새 코어 phase를 만들지 않고 기존 게임 화면의 일시정지 오버레이로 둔다.
- 맵 미리보기는 `KITCHEN_ROWS`와 설비 배치로 정적으로 렌더링하며 Phaser
  게임 월드를 하나 더 실행하지 않는다.
- 현재 기본 스테이지는 모두 버섯 구이 한 종과 같은 주방 맵을 사용하고,
  영입 화면이 없으므로 다음 단계는 `PLAY`로 연결한다.
- 음식 제작 흐름은 UI에 문자열로 복제하지 않고 코어 레시피 레지스트리를 사용한다.

## 완료 조건

- 첫 영업과 다음 스테이지 시작 전에 정보 화면이 한 번씩 표시된다.
- 1280×720에서 제목·전체 맵·3×2 슬롯·상세 정보·TIP·다음 버튼이 겹치지 않는다.
- 음식 호버와 키보드 포커스로 버섯×1 → 조리 도구·불 → 깨끗한 그릇 →
  제출대 흐름을 확인할 수 있다.
- 정보 화면에서는 Q/W/E/R이 선택 명령이 아니며 ESC 설정 후에도 화면이 유지된다.
- 설정 검증, 스테이지 전환, 코어 회귀 테스트와 lint·빌드·브라우저 검증이 통과한다.
