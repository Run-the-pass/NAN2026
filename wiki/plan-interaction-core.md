# 상호작용 코어 완성 계획

## 구현 범위

- 선택한 여러 슬라임을 우클릭한 오브젝트의 작업 타일로 이동시킨다.
- 조리 도구는 한 번에 불 속성 슬라임 한 마리만 작업하게 한다.
- 불 속성이 아닌 슬라임은 조리를 거부하고 로그를 남긴다.
- 재료가 없으면 불 슬라임이 조리 도구 앞에서 기다리고, 버섯이 들어오면 자동으로 조리를 시작한다.
- 조리 도구에 대기·재료 부족·작업 중·작업 완료 상태와 작업자·진행도를 둔다.
- 버섯 상자 → 조리 도구 → 버섯 구이 → 제출대의 한 제작 흐름을 완성한다.
- 저장소 루트의 실행 스크립트가 개발 서버를 시작하고 `/game`을 연다.

## 구현하지 않는 범위

- 추가 요리·레시피, 설비별 속성 조합, 이동 진형과 충돌 회피
- 작업 예약 큐, 업그레이드, 죽음·부활, 카메라 조작
- 기존 D1 플레이 기록 스키마 변경

## 완료 조건

- 복수 선택 명령에서 작업 가능한 한 마리만 조리하고 나머지는 대기하거나 속성 거부를 표시한다.
- 재료 없는 조리 도구에서는 작업이 시작되지 않으며, 버섯 투입 뒤 기다리던 불 슬라임이 자동으로 작업한다.
- 작업 중 오브젝트가 작업자와 0~100% 진행도를 표시한다.
- 완성된 버섯 구이를 운반해 제출하면 목표 수량이 증가한다.
- `play-local.sh`의 셸 구문이 유효하고 실행 권한이 있다.
- 테스트, 린트, 프로덕션 빌드가 통과한다.
