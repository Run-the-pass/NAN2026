# 인게임 맵 UI·로컬 맵 에디터 계획

## 범위

- 인게임 HUD를 상단 주문 카드 최대 3개, 하단 `Q/W/E/R/Space` 선택키,
  우측 슬라임·설비 정보 패널 구조로 재배치한다.
- 슬라임 정보에는 역할과 실제 스탯, 설비 정보에는 실제 상호작용 설명과
  필요한 슬라임·작업 흐름을 표시한다.
- 설비 설명을 자세히 볼 때는 맵을 어둡게 하고 중앙 도움말 카드를 띄우며
  게임 진행을 멈춘다.
- 외곽 조리대와 중앙 작업 섬이 읽히는 기본 14×8 맵으로 바꾼다.
- 맵 행, 7종 설비, 상호작용 타일, 스폰 4칸을 한 데이터 파일로 모으고
  로컬 전용 에디터에서 페인팅·검증·저장할 수 있게 한다.

## 구현하지 않는 범위

- 도마 조리 규칙, 새 음식
- 주문별 1분 만료와 실패 판정. 현재 주문에는 개별 생성 시각·실패 상태가 없다.
- 배포 사이트의 맵 에디터 라우트와 원격 파일 쓰기 API

## 결정

- 맵 에디터는 앱 라우트가 아니라 `127.0.0.1`에만 바인딩되는 Node 표준
  라이브러리 서버로 제공하고 `npm run map:edit`로만 실행한다.
- 저장은 고정 14×8 크기, 설비별 단일 배치, 인접 상호작용 타일, 바닥 위
  스폰을 검증한 뒤 임시 파일을 원자적으로 교체한다.
- 주문 카드의 색상은 개별 주문 시간이 없는 현재 규칙을 꾸미지 않고,
  영업 남은 시간의 40초·20초 경고 구간을 명시적으로 보여 준다.
- 동일 설비 여러 개와 인스턴스별 작업 위치는 후속
  [설비 인스턴스 상태·작업 위치 계획](plan-station-instance-state.md)에서 다룬다.

## 완료 조건

- 1280×720에서 주문 카드 3개, 라운드 정보, 선택키와 우측 정보 패널이
  핵심 맵을 가리지 않고 설비·슬라임 클릭으로 패널 내용이 바뀐다.
- 844×390 가로 화면에서도 선택키·주문 진행·패널 닫기가 가능하다.
- 도움말 오버레이와 설정 중 코어·Phaser가 멈추고 ESC로 원래 화면에 돌아온다.
- `npm run map:edit`는 로컬 주소에서만 열리며 유효한 맵은 바로 저장하고,
  누락 설비·잘못된 작업 타일·스폰·크기는 거부한다.
- 테스트, lint, 프로덕션 빌드, 로컬 에디터 검증과 실브라우저 검수를 통과한다.

## 검증 결과

- **PASS**. 결정론 코어 테스트 30/30, 맵 검증, lint, 프로덕션 빌드와
  `git diff --check`를 통과했다.
- 브라우저에서 1280×720과 낮은 가로 화면의 주문 카드·선택키·정보 패널,
  설비 도움말 중 타이머 정지와 ESC 복귀를 확인했다.
- 에디터에서 160개 타일을 불러오고 수정·복구·저장했다. 유효 저장은 200,
  누락 설비는 422, `localhost` Host 접근은 403으로 확인했다.
