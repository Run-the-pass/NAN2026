# 원본 번개·땅·불 슬라임 적용 계획

## 구현 범위

- `raw/electric.svg`, `raw/earth.svg`, `raw/fire_slime.svg`의 원본 형태와
  장식을 선택 화면·정보 패널·인게임에 적용한다.
- 번개·새싹·불꽃을 제외한 몸통 크기를 물 슬라임과 맞춘다.
- 선택 화면은 원본 표정을 유지한다. Phaser 인게임은 원본 얼굴을 숨기고
  이동 방향·등·깜빡임을 표시하는 얼굴 레이어를 한 번만 그린다.
- 기존 숨쉬기·걷기·젓기·집기 tween을 세 원본 에셋에도 재사용한다.

## 구현하지 않는 범위

- 새 프레임 시트, 속성별 전용 행동 애니메이션, 게임 규칙 변경
- 사용자가 제공한 `raw/` 원본의 수정·이동·삭제

## 완료 조건

- 네 슬라임의 몸통 크기와 바닥선이 실제 게임에서 어색하게 벌어지지 않는다.
- 번개·땅·불 슬라임이 좌·우·상·하 방향과 정지·이동 중 깜빡임을 표시한다.
- 선택 화면의 원본 얼굴, 인게임 얼굴, 축소 정보 패널이 깨지지 않는다.
- 테스트, SVG 문법, lint, 프로덕션 빌드와 브라우저 검수를 통과한다.
