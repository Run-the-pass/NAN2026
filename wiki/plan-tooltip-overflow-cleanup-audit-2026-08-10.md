# 특징 설명 잘림 보정·코드 정리 감사 계획

## 범위

- 우측 정보 패널에서 특징 설명이 패널 경계나 화면 오른쪽에 잘리지 않도록 공통 배치를 보정한다.
- 물·불·번개·땅 슬라임의 특징 설명을 실제 화면에서 확인하고, 휴대폰 가로 규칙이
  공통 배치를 다시 덮어쓰지 않는지 확인한다.
- 현재 GitHub Pages 게임에 필요하지 않거나 중복된 코드·설정·스타일을 저장소 전체에서 찾아 우선순위 보고서로 남긴다.

## 제외 범위

- 보고서에서 찾은 정리 후보는 이번 작업에서 삭제·리팩터링하지 않는다.
- 게임 규칙, 특징 문구, 정보 패널 크기는 바꾸지 않는다.
- `raw/` 원본과 사용자 작업 중 변경은 수정하지 않는다.

## 완료 조건

- 네 슬라임의 특징 설명이 패널과 화면 안에서 온전히 보인다.
- 테스트·타입 검사·린트·Pages 빌드와 실제 브라우저 검증을 통과한다.
- 정리 보고서는 삭제·통합 근거, 예상 절감량, 위험도와 실행 순서를 구분한다.
