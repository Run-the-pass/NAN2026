# UI·인게임 시각 에셋 필요 목록

## 이미 있어 재사용하는 에셋

- 홈 화면 세트: 배경, 로고, 시작·설정 버튼, 책상, 가마솥, 거품, 초록 슬라임
- 물 슬라임과 불 슬라임 SVG
- 음악과 현재 연결된 효과음

## 1순위: 현재 이모지·코드 도형을 교체할 에셋

| 묶음 | 필요한 에셋 | 사용 위치 | 제작 기준 |
| --- | --- | --- | --- |
| 설비 7종 | 재료 상자, 조리 도구, 제출대, 쓰레기 처리 공간, 그릇 생성대, 세척기, 테이블 | 맵, 주문 카드, 설비 정보, 스테이지 정보 | 투명 배경 정사각형 SVG 또는 PNG. 60px 타일에서 외곽 4px 이상 여백 |
| 아이템 4종 | 버섯, 버섯 구이, 깨끗한 그릇, 더러운 그릇 | 주문, 소지품, 작업 흐름, 설비 상태 | 투명 SVG, 16·24·48px에서도 구분되는 단순 실루엣 |
| 주방 타일 | 반복 바닥 1장, 조리대 3×3 연결 타일시트 | 전체 게임 맵 | 이음선 없는 정사영, 북서광 고정, 한 칸 기준 원본 128×128 이상 |
| 슬라임 2종 | 번개 슬라임, 땅 슬라임 | 인게임, 선택 화면, 정보 패널 | 물·불과 같은 몸통 비율·검은 외곽선. 불꽃 같은 장식은 몸통 크기 비교에서 제외 |
| 화재 FX | 발화 1회와 반복 불꽃 | 불난 설비 위 | 투명 4~8프레임 시트 또는 개별 PNG, 60px 타일 안에서 중심 유지 |

설비는 별도 UI 아이콘을 다시 그리지 않고 같은 원본을 축소해 재사용한다.

## 2순위: 플랫폼별 이모지 차이를 없앨 공용 UI 아이콘

- 시간, 주문/접시, 제출 수량, 골드
- 설정, 닫기, 진행 화살표
- 조리, 물/세척, 운반, 보관, 인계, 폐기

SVG 한 벌로 만들고 `currentColor` 또는 단색 변형이 가능하게 한다. 주문 카드
배경, 경고 색 띠, 선택키 원형, 정보 패널 프레임은 CSS로 충분하므로 이미지
에셋을 만들지 않는다.

## 전달 규격

- UI 아이콘: SVG, 정사각 `viewBox`, 폰트·외부 이미지 미포함
- 맵·FX 래스터: 투명 PNG, 2배 원본. 최종 표시 기준은 타일 60×60px
- 파일명은 영문 소문자 kebab-case. 같은 대상을 맵용·UI용으로 중복 제작하지 않는다
- 외곽선 굵기, 북서광 방향, 색상 팔레트를 한 세트 안에서 고정한다
