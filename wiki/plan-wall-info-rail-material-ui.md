# 벽 경로·우측 정보 레일·게임 재질 UI 보정 계획

## 범위

- 모든 슬라임 이동 경로가 설비뿐 아니라 맵의 `#` 벽 타일도 우회한다.
- 데스크톱 게임 맵을 왼쪽 영역에 고정하고 오른쪽을 선택 정보 전용 레일로
  예약해, 정보 패널이 맵을 덮지 않게 한다.
- 캐릭터 선택, HUD·주문 카드·정보 패널, 설정과 게임 오버의 검보라 웹 패널을
  식당의 목재·철제·종이 재질 색과 각진 판형으로 교체한다.

## 제외

- 슬라임끼리의 동적 충돌과 이동 진형은 추가하지 않는다.
- 맵 타일 배치, 주문 규칙, 게임 오버 조건은 바꾸지 않는다.

## 완료 조건

- 벽을 가로지르는 이동 명령에서도 이동 중 슬라임 중심이 벽 충돌 영역에
  들어가지 않고 최종 바닥 좌표에 도착한다.
- 1280×720에서 Phaser 맵이 좌측에 표시되고 우측 정보 레일과 겹치지 않는다.
- 정보 버튼과 설비 선택 시 상세 정보가 우측 레일 안에 바로 표시된다.
- 선택·인게임·게임 오버 화면에 기존 검보라 배경이 남지 않으며 테스트, lint,
  빌드와 브라우저 시각 검수를 통과한다.
