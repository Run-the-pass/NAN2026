# 테이블 조합·14×8 맵 계획

## 범위

- 테이블의 감자와 빈 접시는 어느 순서로 가져와도 한 접시로 합친다.
- 빈 테이블 위 나무 이모지와 `비어 있음` 상태 문구를 제거한다.
- 현재 설비 배치를 보존해 맵·게임 캔버스·미리보기·로컬 에디터를 14×8로 줄인다.
- 하단 조작 버튼만큼 캔버스 영역을 비워 맵과 겹치지 않게 한다.

## 제외 범위

- 테이블 다중 슬롯과 아이템 직접 선택 UI
- 타일 크기, 설비 종류와 스테이지 규칙 변경

## 완료 조건

- 감자→접시와 접시→감자 양쪽 테이블 조합이 코어 테스트를 통과한다.
- 14×8 맵이 유효하고 에디터 저장 검증과 게임 화면이 같은 크기를 사용한다.
- 기본 화면에서 빈 테이블과 하단 조작 버튼이 겹치거나 불필요한 물건을 표시하지 않는다.
