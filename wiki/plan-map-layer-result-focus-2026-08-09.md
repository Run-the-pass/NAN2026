# 맵 표시 레이어·정산 버튼 포커스 보정 계획

## 범위

- 이동·상호작용 하이라이트를 테이블 상판보다 앞, 상판 위 도마·믹서기보다
  뒤에 표시한다.
- 클릭한 슬라임·설비 이름표를 맵 오브젝트와 하이라이트보다 앞에 표시한다.
- 정산의 다음 스테이지·다시 도전 버튼 자동 포커스를 없애 나가기 버튼과 같은
  기본 상태로 연다.

## 하지 않는 것

- 하이라이트 색·크기·판정과 맵 오브젝트 좌표는 바꾸지 않는다.
- 키보드로 직접 이동한 포커스 표시는 없애지 않는다.

## 완료 조건

- 테이블은 하이라이트 아래, 도마·믹서기는 하이라이트 위에 보인다.
- 선택 이름표가 오브젝트·하이라이트에 가리지 않는다.
- 정산을 열었을 때 다음 스테이지 버튼과 나가기 버튼의 테두리 상태가 같다.
- 테스트, 타입 검사, 린트, Pages 빌드와 실제 브라우저 검증을 통과한다.

## 결과

- 공통 깊이를 테이블 `y+1`, 하이라이트 `y+1.5`, 상판 위 도마·믹서기
  `y+2` 순으로 보정했다.
- 슬라임·설비 이름표를 맵 표시 최상단 깊이 `1000`으로 올렸다. 실제
  1280×720 화면에서 `땅 슬라임`, `도마`, `테이블` 이름표가 오브젝트와
  하이라이트에 가리지 않는 것을 확인했다.
- 정산 버튼의 자동 포커스와 결과 화면 전용 갈색 포커스 규칙을 제거했다.
  패배 정산에서 다시 도전·나가기 버튼 모두 `filter: none`, 외곽선 없음으로
  동일했고, 다음 스테이지도 같은 버튼 경로를 사용한다.
- 타입 검사, 린트, 깨끗한 Pages 빌드와 실제 브라우저 검증은 통과했다.
  전체 테스트는 이 작업과 무관하게 공유 작업트리의 테이블 화살표 좌표가
  테스트 기대값과 달라 57/58이었다. 해당 사용자 변경은 덮지 않았다.
- 요청 범위는 `PASS`, 저장소 전체 테스트 상태는 `FIX`로 판정한다.
