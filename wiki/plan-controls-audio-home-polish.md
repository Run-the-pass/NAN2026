# 홈·물 슬라임·이동·음악 설정 보정 계획

## 구현 범위

- 홈 화면을 기존 에셋 배치로 복원하고 새 `logo.svg`만 적용한다.
- 홈과 인게임 설정 버튼에서 위쪽 설정 탭을 열어 음악 켜기·끄기와 음량을 조절한다.
- 음악 설정을 브라우저에 저장하고 일반 음악에서 30초 이하 러쉬 음악으로 즉시 전환한다.
- 라운드 패배 결과 화면에서는 게임 오버 음악으로 즉시 전환한다.
- 선택 화면의 물 슬라임 크기를 다른 슬라임과 맞추고 쫀득하게 위로 늘어나는 반복 애니메이션을 적용한다.
- 인게임 물 슬라임은 다른 속성과 같은 방향별 텍스처를 사용한다.
- 바닥 이동과 오브젝트 이동을 타일 경로가 아닌 클릭 좌표까지의 유클리드 직선 이동으로 변경한다.
- 인게임 슬라임 이름과 우측 슬라임 상태 목록을 숨긴다.

## 구현하지 않는 범위

- 장애물 회피용 내비게이션 메시, 슬라임 간 충돌·진형
- 효과음별 음량과 별도 음소거, 오디오 크로스페이드
- 물 슬라임의 방향별 신규 원본 SVG 제작

## 완료 조건

- 홈이 기존 책상·가마솥·거품·슬라임 배치와 새 `슬라임 레스토랑` 로고를 사용한다.
- 홈과 인게임 설정 탭에서 음악 설정이 즉시 적용되고 페이지 이동 뒤에도 유지된다.
- 남은 시간이 30초 이하가 되면 러쉬 음악 소스로 전환된다.
- 라운드 패배 시 게임 오버 음악 소스로 전환되고 저장된 음악 설정을 유지한다.
- 물 슬라임 선택지의 크기와 반복 탄성이 다른 슬라임과 시각적으로 맞는다.
- 대각선 이동 시 x·y 좌표가 동시에 변하며 최종 클릭 좌표에 도착한다.
- 인게임 이름과 우측 상태 목록이 표시되지 않는다.
- 테스트, 린트, 빌드와 브라우저 실제 동작 검증이 통과한다.
