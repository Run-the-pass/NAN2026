# 튜토리얼 물 이동·크레딧·경로 모션 보정 계획

## 범위

- 튜토리얼에서 퐁당이는 접시를 집은 뒤 목표 테이블 옆으로 옮기는 안내를 먼저 받고,
  현재 안내가 자신을 지목할 때만 이동해 우측으로 선행하지 못하게 한다.
- 푸름이가 튜토리얼 그릇 상자를 누르면 행동을 막되 퐁당이에게 기회를 주라는
  토스트를 클릭 위치에 표시한다.
- 퐁당이 한 명의 행동력 소진으로 턴 종료를 지시하지 않고, 공개된 슬라임 모두의
  행동력이 소진될 때 기존 자동 턴 전환을 쓴다.
- 행동력 설명 대사에서만 슬라임 버튼을 강조하고, 일반 선택·이동 안내에서는
  버튼 펄스를 표시하지 않는다.
- BFS 타일 경로는 유지하되 각 타일에서 감속·재가속하지 않고 일정 속도로 이어 움직인다.
- 크레딧 창을 열면 종이 프레임 전체가 설정창처럼 화면 위에서 내려온다.

## 제외 범위

- 일반 스테이지 이동 규칙, 행동력 비용과 BFS 경로는 바꾸지 않는다.
- 크레딧 닫기 애니메이션과 새로운 모션 라이브러리는 추가하지 않는다.

## 완료 조건

- 푸름이 작업 안내 중 퐁당이의 이동 후보는 없고, 퐁당이 안내에서는 목표에 가까워지는
  기존 이동 후보가 나온다.
- 퐁당이만 행동력을 모두 써도 `턴 종료` 안내가 나오지 않고, 공개된 둘 모두
  행동력을 쓰면 다음 턴으로 자동 전환된다.
- 행동력 설명 대사에서만 슬라임 버튼이 강조된다.
- 여러 타일 이동은 경로의 각 타일 중심을 지나면서 중간 타일에서 속도가 0이 되지 않는다.
- 크레딧 창이 열릴 때 위에서 중앙으로 내려온다.

## 구현·검증 결과

- `PASS`: 퐁당이의 행동력만 0인 경우에도 안내는 유지하고, 공개된 다른 슬라임은
  기존 자동 선택·행동 흐름을 따른다. 둘 다 소진될 때만 자동 턴 전환된다.
- `PASS`: 슬라임 버튼 펄스는 행동력 설명 대사의 `roster` 포커스에만 남기고,
  일반 튜토리얼 선택·이동 안내와 턴 종료 버튼에서는 제거했다.
- `PASS`: 테스트, 타입 검사, lint, 맵·밸런스 검사와 프로덕션 빌드를 통과했다.
