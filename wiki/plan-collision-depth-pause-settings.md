# 충돌·깊이·설정 일시정지 보정 계획

## 구현 범위

- 슬라임의 현재 유클리드 이동을 유지하면서 고정 설비 히트박스를 우회한다.
- 슬라임과 설비의 화면 깊이를 y좌표로 정렬한다.
- 홈과 게임의 설정을 화면 중앙 모달로 표시하고 뒤 화면을 어둡게 한다.
- 게임 설정을 여는 동안 코어와 Phaser 장면을 멈추고, 닫으면 즉시 재개한다.

## 구현하지 않는 범위

- 슬라임끼리 밀어내는 물리와 군집 대형
- 이동 가능한 물체와 동적 장애물
- 음악 외의 추가 설정 항목

## 완료 조건

- 설비를 가로지르는 직선 명령도 설비 히트박스 안으로 들어가지 않고 목적지에 도착한다.
- 슬라임은 설비보다 위쪽에 있으면 뒤에, 아래쪽에 있으면 앞에 그려진다.
- 홈과 게임에서 설정을 열면 중앙 패널과 어두운 배경이 표시된다.
- 게임 설정 중에는 시간이 흐르지 않고, 닫으면 즉시 재개한다.
- 코어 테스트, lint, 프로덕션 빌드가 통과한다.
