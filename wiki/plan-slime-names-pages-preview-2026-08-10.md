# 슬라임 이름·Pages 미리보기 보정 계획

## 범위

- 대화 대본의 이름을 단일 원본으로 삼아 물·불·번개·땅 슬라임의 표시 이름을
  각각 퐁당이·이글이·번쩍이·푸름이로 바꾼다.
- 이름표·로스터·정보 패널·설비 작업 안내·거절 문구·다이얼로그에서 속성명이
  사람 이름 대신 노출되는 부분을 함께 바꾼다. 내부 ID와 속성 규칙은 유지한다.
- 공개 Pages의 현재 배포 버전과 메타데이터를 확인하고, 3분제였던 옛 소개 문구를
  현재 턴제 게임 설명으로 교체한다.

## 제외 범위

- `water`·`fire`·`lightning`·`earth` 내부 ID와 밸런스 데이터는 바꾸지 않는다.
- 사용자가 별도로 요청하지 않은 커밋·푸시·Pages 배포는 하지 않는다.
- 게임 기능과 무관한 새 화면·규칙은 추가하지 않는다.

## 완료 조건

- 네 슬라임의 화면 표시 이름이 대본과 일치한다.
- Pages 빌드의 title·description·Open Graph·Twitter 메타가 현재 게임을 설명한다.
- 테스트·타입 검사·린트·Pages 빌드와 실제 브라우저 확인을 통과한다.

## 확인·검증 결과

- 공개 Pages는 `fd66a82` 빌드이며 `Last-Modified`가 2026-08-09라, 현재 로컬의
  미커밋 작업이 아직 배포되지 않은 상태임을 확인했다.
- 공개 메타의 `3분 안에 주문 5건`은 옛 실시간 규칙 문구였다. 현재 턴제 설명과
  네 슬라임을 담은 가로형 Open Graph·Twitter 카드로 교체했다.
- 테스트 58/58, 타입 검사, 린트와 깨끗한 캐시 Pages 빌드: PASS.
- 실제 Pages 산출물에서 로스터·이름표·정보 패널의 퐁당이·이글이·번쩍이·푸름이와
  새 메타데이터를 확인했고 브라우저 오류가 없었다.
- 최종 가로형 미리보기 카드를 연결한 뒤 Pages와 Sites 배포 빌드를 다시 통과했다.
