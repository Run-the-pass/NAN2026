# 슬라임 레스토랑

네 속성 슬라임을 한 마리씩 움직여 제한된 턴 안에 주문을 완성하는 턴제 식당
운영 게임입니다. Phaser 3와 Next.js로 만들었습니다.

**[브라우저에서 플레이](https://run-the-pass.github.io/NAN2026/)**

## 게임 흐름

재료를 꺼내 설비로 손질·조리하고, 완성한 음식을 접시에 담아 주문대로
제출합니다. 돌아온 더러운 접시는 씻어서 다시 사용해야 합니다.

첫 스테이지는 양배추 주문으로 조작을 익히는 튜토리얼입니다. 이후 스테이지에서
새 슬라임과 화로, 튀김기, 믹서기가 차례로 열립니다. 아르바이트 진행도와 별은
쿠키에 저장되며 마지막 스테이지를 마치면 무한 모드로 이어집니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 슬라임 또는 하단 슬라임 버튼 좌클릭 | 슬라임 한 마리 선택·해제 |
| 표시된 바닥 좌클릭 | 선택한 슬라임 이동 |
| 설비 좌클릭 | 정보 확인, 인접한 슬라임으로 상호작용 |
| 빈 바닥 좌클릭 | 선택 해제 |
| `Space` | 현재 슬라임을 이번 턴에서 쉬게 하고 다음 슬라임 선택 |
| `Esc` | 설정 열기·닫기 |
| `턴 종료` | 남은 행동력을 버리고 다음 턴 시작 |

모든 슬라임이 행동을 마치거나 쉬면 턴은 자동으로 넘어갑니다.

## 슬라임

| 속성 | 턴당 행동력 | 담당 작업 |
| --- | ---: | --- |
| 물 | 1 | 믹서기 물 공급, 접시 세척 |
| 불 | 1 | 화로 조리, 소각 |
| 번개 | 2 | 튀김기 조리, 믹서기 가동 |
| 땅 | 1 | 도마에서 재료 손질 |

현재 메뉴는 채썬 감자·당근·양배추, 구운 감자·버섯, 튀긴 감자·버섯,
바나나·딸기 스무디와 샐러드입니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. macOS에서는
`./play-local.sh`로 개발 서버와 게임 화면을 한 번에 열 수 있습니다.

## 검증

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run build:pages
```

## 주요 파일

- `app/`: 화면, Phaser 게임, 튜토리얼과 다이얼로그
- `game/`: 렌더링과 분리된 게임 규칙, 맵과 밸런스 데이터
- `public/`: 게임에서 사용하는 이미지와 음원
- `wiki/`: 확정된 기획, 구현 계획과 작업 기록
- `raw/`: 사용자 제공 원문과 원본 에셋 — 읽기 전용

밸런스와 레시피, 스테이지는 각각 `game/balance.json`,
`game/recipes.json`, `game/stages.json`에서 관리합니다. `npm run balance:edit`로
로컬 편집기를 열 수 있습니다.
