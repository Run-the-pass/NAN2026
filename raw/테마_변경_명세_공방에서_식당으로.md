# 테마 변경 명세: 공방에서 식당으로

## 1. 변경 목적

- 기존 마법 공방 테마를 식당 운영 테마로 변경한다.
- 약초, 물약, 스크롤 제작 중심의 표현을 음식 재료, 조리 도구, 요리 제작 중심의 표현으로 교체한다.
- 슬라임의 속성별 능력이 식당 업무와 직접 연결되도록 한다.
- 게임의 목표를 공방 생산물 제작에서 제한 시간 내 요리 완성 및 제출로 변경한다.

## 2. 기본 세계관

- 무대는 여러 속성의 슬라임이 운영하는 식당이다.
- 슬라임은 각자의 속성을 이용해 조리, 운반, 세척, 소화 등의 업무를 수행한다.
- 식당에는 일반적인 주방 도구와 속성 기반 설비가 함께 존재한다.
- 현대적인 조리기구를 사용할 수 있다.
- 전자식 조리기구는 번개 슬라임과 연결되는 방향으로 표현한다.
- 전체적인 분위기는 판타지 요소가 포함된 식당으로 통일한다.

## 4. 슬라임 명칭 변경

- 기존 슬라임 종류명
  - 너드 슬라임
  - 날쌘 슬라임
  - 쫑긋 슬라임
  - 일꾼 슬라임

- 변경된 슬라임 종류명
  - 물 슬라임
  - 불 슬라임
  - 번개 슬라임
  - 땅 슬라임

- 기존 종류명은 스탯과 성향을 기준으로 슬라임을 구분했다.
- 변경된 종류명은 속성과 식당 내 담당 업무를 기준으로 슬라임을 구분한다.
- 기존 종류와 변경된 종류는 일대일로 대응하지 않는다.
- 기존 종류별 스탯 조합을 새로운 속성 슬라임에 그대로 이전하지 않는다.
- 신규 문서, UI, 코드 데이터, 로그, 에셋 이름에서는 변경된 속성명을 사용한다.
- 기존 종류명으로 저장된 데이터와 에셋은 새 속성 체계에 맞게 교체하거나 사용 중지한다.
- Q, W, E, R 선택 표시는 각각 물, 불, 번개, 땅 슬라임을 의미한다.
- 음성 호출을 위한 개별 슬라임 이름과 별칭은 사용하지 않는다.

## 6. 공간 구성 변경

- 약초 보관 공간을 식재료 보관 공간으로 변경한다.
- 물약 제작 공간을 조리 공간으로 변경한다.
- 스크롤 제작 공간을 삭제한다.
- 완성품 보관 공간을 완성 음식 대기 공간으로 변경한다.
- 납품 공간을 제출대 또는 서빙대로 변경한다.
- 공방 내부 장식을 식당과 주방에 맞는 가구 및 설비로 교체한다.

## 8. 재료 및 결과물 변경

- 붉은 약초와 푸른 약초는 기본 식재료로 교체한다.
- 물약은 음식 또는 음료로 교체한다.
- 스크롤은 제작 대상에서 제외한다.
- 조리 전 재료와 조리 후 결과물이 시각적으로 구분되어야 한다.
- 완성된 결과물은 그릇에 담긴 음식으로 표현한다.
- 음식 이름과 재료 구성은 식당 테마에 맞게 작성한다.

## 10. 아트 방향

- 기존의 굵은 외곽선, 평면적인 색상, 단순화된 형태를 유지한다.
- 공방 특유의 약초, 물약, 마법진 중심 표현은 줄인다.
- 주방 도구와 음식 재료가 작은 크기에서도 구분되도록 단순화한다.
- 나무, 돌, 금속 재질을 중심으로 식당과 주방의 분위기를 구성한다.
- 전자식 조리기구는 일반 가전 형태를 유지하되 판타지 식당에 어울리게 표현한다.
- 슬라임의 속성색과 조리기구의 기능 표시가 서로 구분되어야 한다.
- 음식, 재료, 그릇, 조리기구는 동일한 시점과 비율로 제작한다.

## 11. 제거 대상

- 약초를 이용한 물약 제작 설정
- 약초를 이용한 스크롤 제작 설정
- 공방 주문서 중심의 표현
- 양조 공방 중심의 배경
- 물약병 중심의 완성품 표현
- 마법진에서 약초가 생성되는 설정
- 식당 운영과 연결되지 않는 공방 전용 오브젝트
- 스크롤 제작용 오브젝트 및 UI
- 너드, 날쌘, 쫑긋, 일꾼 슬라임 종류명
- 기존 종류명에 연결된 스탯 프리셋
- 음성 호출용 개별 이름과 별칭

## 12. 유지 대상

- 물, 불, 번개, 땅의 네 가지 슬라임 속성
- 속성에 따라 수행 가능한 작업이 달라지는 구조
- 재료를 운반하고 도구에 넣어 결과물을 만드는 흐름
- 제한 시간 안에 목표 수량을 달성하는 구조
- 작업 진행도 표시
- 완성품 제출
- 화재와 소화
- 슬라임 선택 및 직접 지시 방식

## 13. 적용 기준

- 신규 문서, UI, 코드, 에셋에서는 공방 관련 용어를 사용하지 않는다.
- 슬라임 종류명은 물, 불, 번개, 땅으로 통일한다.
- 기존 종류명은 신규 시스템의 별칭으로 사용하지 않는다.
- 기존 공방 에셋은 식당 테마와 직접 연결되는 경우에만 수정해 재사용한다.
- 공방 전용 에셋은 비활성화하거나 제거한다.
- 모든 신규 재료, 도구, 결과물은 식당의 조리 과정으로 설명할 수 있어야 한다.
- 각 슬라임의 역할은 식당 업무와 연결되어야 한다.
- 식당 테마 변경이 완료된 뒤에도 기존 조작 방식과 제한 시간 구조는 유지한다.
