# 조작 방식 변경 명세

## 목적

- 기존 음성 명령 중심 조작을 제거한다.
- 마우스와 키보드로 슬라임을 선택하고 이동 및 상호작용을 지시한다.
- 여러 속성의 슬라임을 개별 또는 종류별로 선택할 수 있도록 한다.

## 기본 조작

- 좌클릭
  - 슬라임 한 마리 선택
  - 다른 슬라임을 클릭하면 선택 대상 변경
  - 빈 공간을 클릭하면 선택 해제

- 우클릭
  - 지면을 클릭하면 선택된 슬라임에게 이동 명령
  - 오브젝트를 클릭하면 선택된 슬라임에게 상호작용 명령

- Q
  - 물 슬라임 전체 선택

- W
  - 불 슬라임 전체 선택

- E
  - 번개 슬라임 전체 선택

- R
  - 땅 슬라임 전체 선택

- Space
  - 모든 슬라임 선택

## 선택

- 선택된 슬라임은 화면에서 구분할 수 있어야 한다.
- Q, W, E, R 입력 시 해당 속성의 슬라임 전체를 선택한다.
- Space 입력 시 현재 조작 가능한 모든 슬라임을 선택한다.
- 죽음 상태의 슬라임은 조작할 수 없다.

## 이동

- 선택된 슬라임이 있는 상태에서 지면을 우클릭하면 해당 위치로 이동한다.
- 여러 슬라임이 선택된 경우 선택된 슬라임 모두가 이동 명령을 받는다.
- 이동할 수 없는 위치에는 이동 명령을 수행하지 않는다.

## 상호작용

- 선택된 슬라임이 있는 상태에서 오브젝트를 우클릭하면 해당 오브젝트와 상호작용한다.
- 슬라임은 오브젝트 위치로 이동한 뒤 작업을 수행한다.
- 해당 작업을 수행할 수 없는 슬라임은 작업을 거부한다.
- 작업 거부 시 로그를 통해 작업 불가 상태를 알린다.
- 작업 오브젝트에 필요한 재료가 부족하면 해당 위치에서 대기한다.
- 대기 중 재료가 추가되면 작업을 시작한다.

## 슬라임 상태

- 대기 상태
  - 아무 작업도 수행하지 않는다.

- 이동 상태
  - 명령받은 위치 또는 오브젝트로 이동한다.

- 상호작용 상태
  - 지정된 오브젝트의 작업을 수행한다.

- 죽음 상태
  - 조작할 수 없다.
  - 5초 후 부활 애니메이션과 함께 스폰 위치로 돌아간다.
  - 부활 후 대기 상태가 된다.
  - 죽음과 부활은 로그로 알린다.

## 카메라

- 맵이 화면보다 큰 경우 카메라 이동 기능을 사용한다.
- 구체적인 카메라 조작 방식은 별도로 확정한다.

## 제거 대상

- 음성 입력
- 음성 인식 결과
- 호출명을 통한 슬라임 선택
- 음성 명령 해석
- 음성 명령과 관련된 청력 및 집중력 판정

## 미정 사항

- 복수 선택 방식
- 선택 추가 및 해제 방식
- 여러 슬라임이 같은 위치로 이동할 때의 배치 방식
- 기존 명령이 있는 슬라임에게 새 명령을 내렸을 때의 처리
- 하나의 오브젝트에 여러 슬라임이 명령받았을 때의 처리
- 시설별 동시 작업 가능 인원
- 아이템을 직접 클릭했을 때의 운반 처리
- 명령 예약 및 명령 대기열
- 카메라 이동 방식
- 오브젝트 정보 확인 방식
