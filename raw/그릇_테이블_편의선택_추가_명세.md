# 그릇 시스템 및 편의 선택 조작 추가 명세

## 1. 작업 목적

- 음식 제작부터 제출, 세척까지 이어지는 그릇 순환 구조를 추가한다.
- 테이블을 재료, 그릇, 음식의 임시 보관 장소로 사용한다.
- 여러 슬라임을 빠르게 선택할 수 있는 편의 조작을 추가한다.
- 기존 좌클릭 선택, 우클릭 이동 및 상호작용 구조를 유지한다.
- ESC 입력은 선택 해제가 아니라 설정 및 일시정지 화면 호출에 사용한다.

# 그릇 시스템

## 2. 그릇의 역할

- 완성 음식은 그릇에 담긴 상태에서만 제출할 수 있다.
- 그릇은 재료 및 완성 음식을 담아 운반하는 아이템이다.
- 그릇 수량은 제한된 자원으로 취급한다.
- 사용한 그릇은 세척한 뒤 다시 사용할 수 있다.
- 그릇이 부족하면 새로운 음식을 제출할 수 없으므로 그릇 회수가 필요하다.

## 3. 그릇 상태

- 깨끗한 빈 그릇
  - 음식이나 재료를 담을 수 있다.
  - 그릇 생성대 또는 테이블에 놓을 수 있다.

- 내용물이 담긴 그릇
  - 재료 또는 완성 음식이 들어 있다.
  - 담긴 내용물의 종류를 저장한다.
  - 제출 가능한 음식인지 구분할 수 있어야 한다.

- 더러운 그릇
  - 음식을 제출한 뒤 생성된다.
  - 새로운 재료나 음식을 담을 수 없다.
  - 세척기 또는 설거지 시설에서 세척해야 한다.

- 폐기 처리 중인 그릇
  - 잘못 만든 음식과 함께 폐기 시설에 들어간 상태다.
  - 폐기 완료 후 빈 그릇으로 복구할지 새 그릇을 생성할지는 기존 폐기 규칙과 연결한다.

## 4. 그릇 생성

- 라운드 시작 시 정해진 수량의 깨끗한 그릇을 생성한다.
- 생성된 그릇은 그릇 생성대에 배치한다.
- 초기 그릇 수량은 데이터로 변경할 수 있도록 한다.
- 그릇 생성대가 가득 찬 경우 추가 그릇을 겹쳐 생성하지 않는다.
- 라운드 종료 시 그릇과 내용물의 상태를 초기화한다.

## 5. 그릇 운반

- 슬라임은 깨끗한 그릇, 내용물이 담긴 그릇, 더러운 그릇을 운반할 수 있다.
- 일반 슬라임의 기본 운반 가능 그릇 수는 1개로 한다.
- 땅 슬라임의 다중 그릇 운반 수량은 슬라임 스탯 문서에서 정의한다.
- 여러 그릇을 운반할 때 각 그릇의 상태와 내용물을 유지한다.
- 슬라임이 그릇을 들고 있는 상태를 화면에서 확인할 수 있어야 한다.
- 운반 중인 슬라임에게 새로운 운반 명령을 내렸을 때의 처리는 기존 아이템 운반 규칙을 따른다.

## 6. 음식과 그릇

- 음식이 완성되면 빈 그릇에 담아야 제출할 수 있다.
- 그릇에 이미 내용물이 있으면 다른 음식이나 재료를 추가할 수 없다.
- 제출대는 그릇에 담긴 완성 음식만 받는다.
- 제출된 음식이 현재 주문과 일치하면 주문 진행도를 증가시킨다.
- 제출이 완료되면 음식은 제거되고 그릇은 더러운 상태가 된다.
- 주문과 일치하지 않는 음식의 제출 처리는 주문 시스템의 규칙을 따른다.

## 7. 그릇 세척

- 더러운 그릇은 세척기 또는 설거지 시설로 운반한다.
- 물 슬라임만 그릇 세척 작업을 수행할 수 있다.
- 세척이 완료되면 더러운 그릇을 깨끗한 빈 그릇으로 변경한다.
- 세척된 그릇은 시설 내부에 남거나 지정된 배출 위치에 생성한다.
- 세척 시설의 최대 수용량과 작업 시간은 데이터로 관리한다.
- 세척 중인 그릇은 다른 슬라임이 집을 수 없다.

# 테이블 시스템

## 8. 테이블의 역할

- 테이블은 재료, 빈 그릇, 음식이 담긴 그릇, 더러운 그릇을 잠시 내려놓는 공간이다.
- 테이블 자체는 재료를 가공하거나 음식을 조리하지 않는다.
- 플레이어는 테이블을 이용해 운반 경로를 나누고 작업 대기열을 정리할 수 있다.
- 테이블은 슬라임이 이동할 수 없는 고정 오브젝트로 취급한다.
- 슬라임은 테이블과 인접한 이동 가능 위치에서 상호작용한다.

## 9. 테이블 보관 규칙

- 테이블의 각 보관 위치에는 하나의 아이템 또는 하나의 그릇만 둘 수 있다.
- 테이블의 수용량은 오브젝트 데이터로 관리한다.
- 비어 있는 보관 위치가 없으면 새로운 아이템을 올릴 수 없다.
- 테이블 위 아이템은 다른 슬라임이 가져갈 수 있다.
- 테이블 위 그릇의 상태와 내용물은 그대로 유지한다.
- 테이블은 자동으로 아이템을 분류하거나 이동시키지 않는다.
- 테이블 위에 놓을 수 없는 오브젝트는 상호작용을 거부한다.

## 10. 테이블 상호작용

- 아이템이나 그릇을 든 슬라임이 테이블을 우클릭하면 빈 보관 위치에 내려놓는다.
- 빈손인 슬라임이 아이템이 놓인 테이블을 우클릭하면 해당 아이템을 집는다.
- 여러 아이템이 놓여 있을 때 어떤 아이템을 집을지는 선택 가능한 보관 위치 또는 별도 우선순위 규칙으로 처리한다.
- 아이템 선택 방식이 확정되지 않은 경우 임의로 가장 오래된 아이템을 집도록 구현하지 않는다.
- 테이블이 가득 찼거나 집을 수 있는 아이템이 없으면 작업 불가 상태를 표시한다.

# 편의 선택 조작

## 11. 기본 선택

- 슬라임을 좌클릭하면 해당 슬라임만 선택한다.
- Shift를 누르지 않은 상태에서 다른 슬라임을 좌클릭하면 기존 선택을 해제하고 새 슬라임만 선택한다.
- 빈 공간을 좌클릭하면 현재 선택을 해제한다.
- 선택된 슬라임은 외곽선, 바닥 표시 또는 선택 아이콘으로 구분한다.
- 우클릭은 선택된 슬라임의 이동 및 상호작용 명령에 사용한다.

## 12. Shift 선택

- Shift를 누른 상태에서 슬라임을 좌클릭하면 현재 선택에 해당 슬라임을 추가한다.
- 이미 선택된 슬라임을 Shift와 함께 좌클릭하면 선택에서 제외한다.
- Shift 선택은 서로 다른 속성의 슬라임에도 사용할 수 있다.
- Shift 선택 중 기존 선택 상태를 유지한다.

## 13. 드래그 범위 선택

- 빈 공간에서 좌클릭을 누른 채 드래그하면 선택 영역을 표시한다.
- 마우스 버튼을 놓으면 선택 영역 안에 포함된 슬라임을 선택한다.
- Shift 없이 드래그하면 기존 선택을 해제하고 범위 안의 슬라임만 선택한다.
- Shift를 누른 채 드래그하면 범위 안의 슬라임을 기존 선택에 추가한다.
- 선택 영역은 드래그가 시작된 지점과 현재 마우스 위치를 기준으로 표시한다.
- 드래그 거리가 매우 짧으면 범위 선택이 아니라 일반 좌클릭으로 처리한다.
- UI 위에서 시작한 드래그는 범위 선택으로 처리하지 않는다.
- 죽음 상태이거나 조작 불가능한 슬라임은 범위 선택에서 제외한다.

## 14. 단축키 선택

- Q
  - 물 슬라임 전체 선택

- W
  - 불 슬라임 전체 선택

- E
  - 번개 슬라임 전체 선택

- R
  - 땅 슬라임 전체 선택

- Space
  - 현재 조작 가능한 모든 슬라임 선택

- 단축키 선택은 화면 밖에 있는 슬라임도 포함한다.
- Shift와 단축키를 함께 사용할 때 선택을 추가할지는 별도 확정 사항으로 둔다.

## 15. ESC 및 설정

- ESC는 슬라임 선택 해제에 사용하지 않는다.
- 게임 중 ESC를 누르면 설정 및 일시정지 화면을 연다.
- 설정 화면이 열린 동안 게임 진행을 정지한다.
- 다음 항목을 함께 정지한다.
  - 라운드 제한 시간
  - 슬라임 이동
  - 슬라임 작업
  - 조리 진행도
  - 주문 타이머
  - 화재 발생 타이머
  - 화재 전파 타이머

- 설정 화면에서 게임으로 돌아가면 일시정지를 해제한다.
- 설정 화면이 열린 상태에서 ESC를 다시 눌렀을 때 닫을지는 설정 UI 규칙에서 정의한다.
- 설정 화면을 닫은 뒤 재개 카운트다운을 사용할지는 별도 확정 사항으로 둔다.

# 테스트

## 16. 그릇 생성 테스트

- 라운드 시작 시 설정된 수량만큼 깨끗한 그릇이 생성되는지 확인한다.
- 그릇이 모두 서로 다른 게임 오브젝트로 생성되는지 확인한다.
- 생성대 수용량을 초과해 그릇이 겹치지 않는지 확인한다.
- 라운드 재시작 시 이전 라운드의 그릇이 남지 않는지 확인한다.

## 17. 그릇 상태 전환 테스트

- 깨끗한 그릇에 음식이 정상적으로 담기는지 확인한다.
- 내용물이 있는 그릇에 다른 내용물을 추가할 수 없는지 확인한다.
- 완성 음식이 담긴 그릇만 제출 가능한지 확인한다.
- 제출 후 음식이 제거되고 그릇이 더러운 상태가 되는지 확인한다.
- 더러운 그릇에 음식이나 재료를 담을 수 없는지 확인한다.
- 물 슬라임의 세척 완료 후 깨끗한 그릇으로 돌아오는지 확인한다.

## 18. 그릇 운반 테스트

- 일반 슬라임이 기본 수량을 초과해 그릇을 들지 못하는지 확인한다.
- 땅 슬라임의 운반량이 설정된 수치와 일치하는지 확인한다.
- 여러 그릇을 운반할 때 각 그릇의 내용과 상태가 섞이지 않는지 확인한다.
- 운반 중 이동 명령과 시설 상호작용이 정상적으로 연결되는지 확인한다.
- 슬라임이 사망하거나 제거될 경우 들고 있던 그릇이 유실되지 않는지 확인한다.

## 19. 테이블 테스트

- 빈 테이블에 아이템과 그릇을 내려놓을 수 있는지 확인한다.
- 테이블 수용량을 초과해 아이템을 놓을 수 없는지 확인한다.
- 테이블에 놓인 아이템을 다른 슬라임이 집을 수 있는지 확인한다.
- 테이블 위 그릇의 상태와 내용물이 유지되는지 확인한다.
- 더러운 그릇과 깨끗한 그릇을 각각 정상적으로 보관할 수 있는지 확인한다.
- 테이블이 이동 경로를 막고 슬라임이 인접 위치에서 상호작용하는지 확인한다.
- 테이블이 가득 찬 경우 작업 불가 표시가 출력되는지 확인한다.
- 여러 아이템이 놓인 테이블에서 의도하지 않은 아이템이 집히지 않는지 확인한다.

## 20. 개별 및 Shift 선택 테스트

- 일반 좌클릭으로 한 마리만 선택되는지 확인한다.
- 다른 슬라임을 좌클릭했을 때 기존 선택이 교체되는지 확인한다.
- Shift와 좌클릭으로 선택이 추가되는지 확인한다.
- 선택된 슬라임을 Shift와 좌클릭했을 때 선택에서 제외되는지 확인한다.
- 서로 다른 속성의 슬라임을 함께 선택할 수 있는지 확인한다.
- 빈 공간 좌클릭으로 선택이 해제되는지 확인한다.

## 21. 드래그 선택 테스트

- 드래그 영역 안의 슬라임만 선택되는지 확인한다.
- 영역 경계에 걸친 슬라임의 선택 판정이 일관적인지 확인한다.
- Shift 없이 드래그했을 때 기존 선택이 교체되는지 확인한다.
- Shift와 함께 드래그했을 때 기존 선택에 추가되는지 확인한다.
- 짧은 드래그가 일반 좌클릭으로 처리되는지 확인한다.
- UI 위에서 드래그했을 때 범위 선택이 시작되지 않는지 확인한다.
- 화면 확대, 축소 또는 카메라 이동 후에도 선택 영역과 실제 슬라임 위치가 일치하는지 확인한다.
- 사망 상태의 슬라임이 범위 선택에 포함되지 않는지 확인한다.

## 22. 단축키 및 ESC 테스트

- Q, W, E, R이 각각 올바른 속성의 슬라임만 선택하는지 확인한다.
- Space가 모든 조작 가능한 슬라임을 선택하는지 확인한다.
- 화면 밖 슬라임도 단축키 선택에 포함되는지 확인한다.
- ESC 입력 시 선택이 해제되지 않고 설정 화면이 열리는지 확인한다.
- 설정 화면이 열린 동안 게임 타이머와 모든 작업이 멈추는지 확인한다.
- 설정 화면을 닫은 뒤 타이머와 작업이 중복 실행되지 않고 정상 재개되는지 확인한다.

## 23. 통합 테스트

- 테이블에 빈 그릇을 올려둔 뒤 다른 슬라임이 가져갈 수 있는지 확인한다.
- 완성 음식을 그릇에 담아 테이블에 보관한 뒤 제출할 수 있는지 확인한다.
- 제출 후 생긴 더러운 그릇을 테이블에 두었다가 물 슬라임이 세척할 수 있는지 확인한다.
- 여러 슬라임을 드래그로 선택해 그릇 또는 테이블에 명령했을 때 한 오브젝트의 상호작용 규칙과 충돌하지 않는지 확인한다.
- Shift 선택으로 운반 슬라임과 작업 슬라임을 함께 선택한 뒤 각 속성의 작업 불가 처리가 정상적으로 표시되는지 확인한다.
- 설정 화면을 열었다 닫아도 그릇 상태, 테이블 내용물, 선택 상태가 손상되지 않는지 확인한다.

## 24. 완료 조건

- 그릇이 생성, 사용, 제출, 오염, 세척의 순서로 순환한다.
- 테이블에서 아이템과 그릇을 임시 보관하고 다시 가져갈 수 있다.
- 그릇과 테이블의 상태가 라운드 진행 중 손실되거나 섞이지 않는다.
- 좌클릭, Shift 선택, 드래그 선택이 서로 충돌하지 않는다.
- Q, W, E, R, Space 선택이 기존 조작과 함께 정상 작동한다.
- ESC 입력 시 설정 및 일시정지 화면이 열린다.
- 설정 화면이 열린 동안 게임 진행이 완전히 정지한다.
- 관련 단위 테스트와 통합 테스트를 통과한다.

## 25. 미정 사항

- 초기 그릇 수량
- 그릇 생성대의 최대 수용량
- 세척 시설의 최대 수용량
- 세척 작업 시간
- 땅 슬라임의 정확한 그릇 운반량
- 폐기 후 그릇 복구 방식
- 테이블 한 개의 보관 가능 수량
- 여러 아이템이 있는 테이블의 대상 선택 방식
