# 화면별 기획

`raw/추가본.pptx` 15장을 화면 단위로 정리했다. 슬라이드 크기는 1280×720
이지만 **치수는 상대적인 참고값이며 절대 px 규격이 아니다**(2026-08-02
사용자 확인). 아래에는 비율과 개수만 남기고 좌표는 적지 않는다.

## 1. 덱의 성격 (1~2장)

"완성도를 올린다 판단되는 부분들"을 모은 추가 제안이다. 필수 명세가
아니라 후보 목록에 가깝고, 실제로 랭킹 시스템에는 "안 넣어도 되는데,
넣는다면" 이라는 단서가 붙어 있다.

## 2. 화면 전개 (4장)

```text
스테이지 소개 → 로딩 → 인게임 → 정산
  → 다음 스테이지 소개 → 슬라임 추가 멤버 → 로딩 → 인게임 → …
```

- 패배하면 정산 대신 패배 정산 창으로 간다.
- 이 루프에서 현재 구현된 것은 `인게임` 하나뿐이다.

## 3. 메인 화면 (3장)

- 필요한 것은 `게임 시작`, `설정` 둘뿐이다.
- 덱의 메모: "이 부분은 기존에 만든 거 사용해도 될 것 같아보여요."

## 4. 스테이지 소개 (5·6·11·12장)

같은 화면의 두 변형이다. 6·12장에만 호버 설명이 붙어 있다.

**구성**

- 상단: 스테이지 번호와 이름 (`3-3 : …` 형식)
- 좌측: 스테이지 일러스트 (가로가 세로보다 긴 직사각형)
- 우측: `나올 수 있는 음식 목록` 패널
- 하단: TIP 문구, 그 아래 `다음` 버튼

**제약**

| 항목 | 제한 |
|---|---|
| 스테이지 이름 | 한글·특수문자·공백 포함 30자 이내 |
| TIP | 최대 2줄, 공백 포함 30자 이내 |

**음식 목록**

- 슬롯이 **2행 × 3열, 총 6칸**이다. 모두 같은 크기의 원형이다.
- 호버링하면 그 음식의 **재료 제작 아이콘**을 표기한다 (6·12장).

## 5. 인게임 (7·8장)

- 7장은 맵 이미지 한 장이며 `제출처`만 표시돼 있다.
- 맵 이미지에는 **냄비 2개와 도마 2개**가 있다. 조리 도구가 복수라는
  뜻이며, 화재 전파가 실제로 일어날 수 있는 배치다.
- 8장은 조작 키다: `Q` `W` `E` `R` `Space`.
- 8장 메모: "28P는 현재 공사중. 메뉴 디자인을 아직 구현 못했어요."

## 6. 라운드 정산 (9장)

전체를 어둡게 깔고 중앙에 카드를 띄운다. 세로로 긴 카드다.

**표 구조** — 3열이다.

| 항목 | 계산식 | 소계 |
|---|---|---|
| 주문 성공 횟수 | 99번 × 1000점 | 99999점 |
| 주문 실수 횟수 | 99번 × -1000점 | -99999점 |
| 슬라임 죽음 | 99번 × -500점 | -99999점 |
| 화재 타일 | 99번 × -100점 | -9999점 |
| **합계** | | **999999점** |

- 구분선은 3개이며 2행·3행·4행 뒤에 있다. 성공/실수를 한 묶음으로
  본다는 뜻으로 읽힌다.
- 상단에 `라운드 클리어 로고`, 하단에 `다음` 버튼.
- **회의 결정에 따라 점수와 슬라임 죽음은 쓰지 않는다.** 02 문서 참고.

## 7. 게임 오버 (10장)

정산과 같은 형태지만 카드가 더 짧고 항목이 하나다.

| 항목 | 계산식 | 소계 |
|---|---|---|
| 주문 목표 | 99번 × 1000점 | 99999점 |
| **합계** | | **999999점** |

- 하단 버튼 2개: `1-1부터`, `타이틀로`.
- 중간 이어하기는 없다. 실패하면 스테이지 진행을 처음부터 다시 한다.

## 8. 슬라임 추가 선택 (13·14·15장)

라운드 사이 영입 화면이다. 세 장은 같은 화면의 변형이다.

**구성**

- 상단: `추가할 슬라임을 선택하세요!`
- 가운데: 세로로 긴 카드 **4장**을 가로로 나란히
- 카드 안: 슬라임 아트 → 이름 → `하는 일` → 아이콘 **2개**
- 하단: `추천 슬라임 : ○○○` (공백 포함 최대 6자), 그 아래 `확인` 버튼

**후보 4종** — 불 / 물 / 풀 / 번개

- 15장 메모: "캐릭터 선택 시 - 해당 버튼 클릭 시 흰색 테두리로 강조"
- 아트 크기가 카드마다 제각각이지만 상대 규격이므로 구현에서 맞추면 된다.
- **회의 결정: 이미 데려온 속성도 다시 뽑을 수 있다.** 따라서 후보는 항상
  4종이고 카드가 비는 경우가 없다.
- **명칭 주의**: 덱과 아트는 `풀 슬라임`이지만 확정 명칭은 `땅 슬라임`
  이다. 02 문서 참고.

## 9. 에셋

덱에 포함된 이미지 11개 중 확인한 것:

- 슬라임 스티커 아트 (번개=노랑+번개 뿔, 풀=연두+새싹)
- 주방 바닥 타일 패턴 (주황 계열 체크)
- 인게임 맵 목업 (냄비 2, 도마 2, 제출처, 슬라임 4마리 배치)
- 빈 접시, 음식(감자 요리류) 스티커 아트
