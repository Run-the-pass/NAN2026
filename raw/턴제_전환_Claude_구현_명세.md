# 실시간 방식에서 턴제로 전환

## 1. 문서 목적

기존 실시간 방식의 슬라임 이동 및 행동 시스템을 턴제로 전환한다.

이 문서는 다음 내용을 정리한다.

- 슬라임별 행동력
- 행동별 행동력 소모
- 유효하지 않은 상호작용 처리
- 스테이지와 주문 진행 방식
- 슬라임 충돌
- 기구별 사용 가능한 슬라임
- 턴 진행 순서
- 조리 진척도
- 테이블 상호작용
- 기본 조작과 후순위 조작
- 제거할 기존 요소
- 슬라임 수

## 2. 전환 개요

기존에는 시간 단위로 슬라임들이 이동하고 행동했으나, 변경 후에는 턴 단위로 이동하고 행동한다.

슬라임의 이동과 행동은 모두 **행동력**이라는 단위로 통일한다.

## 3. 슬라임별 행동력

| 슬라임 | 턴당 행동력 |
|---|---:|
| 전기 슬라임 | 2 |
| 그 외 슬라임 | 1 |

- 매 턴이 시작될 때 모든 슬라임의 행동력이 초기화된다.
- 플레이어는 원한다면 슬라임의 행동력을 사용하지 않고 턴을 넘길 수 있다.

## 4. 행동별 행동력 소모

| 분류 | 행동 | 소모 행동력 |
|---|---|---:|
| 이동 | 상, 하, 좌, 우 중 한 방향으로 1칸 이동 | 1 |
| 물건 | 물건 집어 들기 | 1 |
| 물건 | 물건 내려놓기 | 1 |
| 조리 | 도마 사용 | 2 |
| 조리 | 튀김기 사용 | 2 |
| 조리 | 화로 사용 | 2 |
| 믹서기 | 믹서기 내용물 채우기 | 1 |
| 믹서기 | 믹서기 사용 | 2 |
| 세척기 | 더러운 그릇을 세척기에 넣기 | 1 |
| 세척기 | 세척기에서 그릇 세척 | 2 |

## 5. 유효하지 않은 상호작용

다음 행동은 애초에 유효하지 않은 상호작용이므로 행동력을 소모하지 않는다.

| 상황 | 처리 |
|---|---|
| 잘못된 속성의 슬라임으로 기구 클릭 | 행동하지 않음 |
| 빈손으로 빈 테이블 사용 | 행동하지 않음 |
| 물건을 들고 있는 상태에서 다른 물건 집기 | 행동하지 않음 |
| 물건을 들고 있는 상태에서 조리 등 다른 상호작용 시도 | 행동하지 않음 |

유효하지 않은 상호작용을 시도하면 토스트 알림으로 해당 행동이 불가능한 이유를 표시한다.

## 6. 스테이지와 주문 진행 방식

### 6.1 턴 제한

- 주문별로 별도의 턴 제한을 두지 않는다.
- 턴 제한은 스테이지 전체에 할당한다.

### 6.2 현재 처리 가능한 주문

| 항목 | 규칙 |
|---|---|
| 동시 처리 가능한 레시피 | 2개 |
| 표시 위치 | 좌측 상단 |
| 표시 방식 | 주문 카드 |
| 주문 처리 후 | 다음 레시피가 들어와 다시 2개를 채움 |

### 6.3 레시피 순서

- 스테이지별로 미리 레시피 리스트를 지정한다.
- 주문은 해당 리스트를 기준으로 순서대로 제공한다.
- 현재 주문 다음에 등장할 레시피 2개를 미리 보여준다.
- 다음 레시피 2개는 현재 레시피 표시 영역의 우측 상단에 작게 표시한다.

### 6.4 스테이지 통과와 랭크

- 스테이지마다 통과에 필요한 최소 주문 처리 수를 지정한다.
- 최소 주문 수 이상을 처리하면 스테이지를 통과한다.
- 통과 기준보다 더 많은 주문을 처리하면 스테이지 해결 랭크가 높아진다.

예시:

| 처리 결과 | 랭크 |
|---|---|
| 통과 기준만 달성 | 별 1개 |
| 통과 기준보다 주문 2개 추가 처리 | 별 2개 |
| 통과 기준보다 주문 3개 추가 처리 | 별 3개 |

## 7. 슬라임 충돌

| 상황 | 허용 여부 |
|---|---|
| 두 슬라임이 같은 칸에 위치 | 불가능 |
| A 슬라임이 점유한 칸으로 B 슬라임 이동 | 불가능 |
| 서로 인접한 A 슬라임과 B 슬라임이 한 턴에 자리 교환 | 불가능 |

## 8. 기구별 사용 가능한 슬라임

| 기구 | 행동 | 사용 가능한 슬라임 |
|---|---|---|
| 재료 상자 | 사용 | 모든 슬라임 |
| 도마 | 사용 | 땅 슬라임 |
| 소각기 | 물건 버리기 | 모든 슬라임 |
| 소각기 | 소각하기 | 불 슬라임 |
| 화로 | 사용 | 불 슬라임 |
| 튀김기 | 사용 | 전기 슬라임 |
| 믹서기 | 내용물 채우기 | 물 슬라임 |
| 믹서기 | 실행 | 전기 슬라임 |
| 세척기 | 더러운 그릇 넣기 | 모든 슬라임 |
| 세척기 | 그릇 세척 | 물 슬라임 |

## 9. 턴 진행

턴은 다음 순서로 진행된다.

1. 턴 시작
2. 모든 슬라임 행동력 초기화
3. 플레이어가 원하는 순서로 슬라임 조작
4. 플레이어가 턴 종료 버튼 선택
5. 남은 행동력 소멸
6. 스테이지 남은 턴 1 감소
7. 다음 턴 시작

추가 규칙:

- 한 턴 동안 모든 슬라임이 각자의 행동력을 사용할 수 있다.
- 플레이어는 일부 또는 모든 슬라임의 행동력을 사용하지 않고 턴 종료 버튼을 누를 수 있다.
- 턴 종료 시 사용하지 않은 행동력은 모두 소멸한다.
- 턴 종료 후 스테이지의 남은 턴이 1 감소한다.

## 10. 조리 진척도

| 상황 | 처리 |
|---|---|
| 행동력을 소모해 조리 | 소모한 행동력만큼 조리 진척도 증가 |
| 조리를 중간에 중단 | 현재까지 오른 진척도 유지 |
| 이후 다시 조리 | 기존 진척도에 이어서 진행 |

## 11. 테이블 상호작용

### 11.1 기본 원칙

슬라임이 어떤 물건을 들고 있든 테이블과 상호작용할 때, 두 물건이 함께 있을 수 있다면 테이블에 내려놓는 방향으로 처리한다.

### 11.2 상황별 처리

| 슬라임 상태 | 테이블 상태 | 결과 |
|---|---|---|
| 그릇을 들고 있음 | 음식이 있음 | 그릇을 테이블에 내려놓고 음식이 그릇에 담김 |
| 음식을 들고 있음 | 그릇이 있음 | 음식을 그릇에 내려놓고 음식이 담긴 그릇이 테이블에 남음 |
| 빈손 | 음식이 담긴 그릇이 있음 | 음식이 담긴 그릇을 집어 듦 |
| 다른 물건을 들고 있음 | 조합이 성립하지 않는 물건이 있음 | 아무 동작도 하지 않음 |

### 11.3 세부 처리 순서

#### 그릇을 들고 음식이 있는 테이블과 상호작용

1. 슬라임이 들고 있던 그릇을 테이블에 내려놓는다.
2. 테이블에 있던 음식이 그릇에 담긴다.
3. 음식이 담긴 그릇이 테이블 위에 남는다.

#### 음식을 들고 그릇이 있는 테이블과 상호작용

1. 슬라임이 들고 있던 음식을 그릇에 내려놓는다.
2. 음식이 담긴 그릇이 테이블 위에 남는다.

#### 빈손으로 음식이 담긴 그릇과 상호작용

- 슬라임은 음식이 담긴 그릇을 집어 든다.

#### 이미 다른 물건을 들고 있는 경우

- 들고 있는 물건과 테이블 위 물건의 상호작용이 성립하지 않으면 아무 동작도 하지 않는다.

## 12. 조작법

### 12.1 기본 조작

1. 슬라임을 좌클릭해 선택한다.
2. 선택된 슬라임 주변의 상, 하, 좌, 우 한 칸에 이동 가능 표시를 출력한다.
3. 이동 가능 표시를 좌클릭하면 해당 위치로 이동한다.

```text
    위
왼쪽  슬라임  오른쪽
    아래
```

### 12.2 후순위 조작

다음 기능은 필요할 경우 추가하되 후순위 작업으로 둔다.

| 기능 | 우선순위 |
|---|---|
| 선택한 슬라임을 `WASD` 또는 화살표 키로 이동 | 후순위 |
| 한 슬라임의 행동이 끝나면 자동으로 다른 슬라임 선택 | 후순위 |
| 스페이스바로 현재 슬라임의 턴 쉬기 | 후순위 |

## 13. 기존 게임에서 제거할 요소

턴제 전환에 따라 다음 요소를 제거한다.

| 제거 대상 | 처리 |
|---|---|
| 기존 `Q`, `W`, `E`, `R`, `Space` 선택 조작 | 제거 |
| 주문 카드 내부의 시간 게이지 | 제거 |
| 슬라임 선택 화면 | 제거 |

| 항목 | 규칙 |
|---|---|
| 게임 시작 시 슬라임 수 | 4마리 |
| 게임 도중 증가 | 없음 |
| 게임 도중 감소 | 없음 |
