# 슬라임 스탯, 요리 가격과 패널티

## 문서 목적

이 문서는 슬라임 종류별 스탯, 강화 방식, 타일 기반 주방에서의 행동 규칙, 요리 판매 가격과 실패 패널티를 규정한다.

현재 해커톤 구현에서 사용하는 슬라임 스탯은 다음 네 가지뿐이다.

- 작업 속도
- 이동 속도
- 청력
- 집중력

성격, 배고픔, 숙련 행동과 같은 요소는 스탯을 추가하는 대신 별도의 특성 또는 상태로 표현한다.

## 타일 기반 주방

주방은 자유롭게 배치된 오브젝트가 아니라 타일 격자로 구성된 맵이다. 바닥, 테이블, 조리대와 조리 기구가 각각 타일을 차지한다.

### 타일 종류

| 종류 | 이동 | 설명 |
|---|---:|---|
| 바닥 | 가능 | 플레이어와 슬라임이 이동하는 타일 |
| 테이블·조리대 | 불가능 | 이동을 막으며 물건을 올려둘 수 있음 |
| 작업대 | 불가능 | 손질, 세척, 조리 등의 작업이 발생하는 타일 |
| 재료 공급대 | 불가능 | 재료가 생성되거나 보충되는 타일 |
| 서빙대 | 불가능 | 완성된 요리를 손님에게 전달하는 타일 |

플레이어와 슬라임은 이동 가능한 바닥 타일만 밟을 수 있다. 테이블이나 작업대를 사용하려면 해당 타일과 상하좌우로 인접한 바닥 타일까지 이동해야 한다.

경로 탐색과 거리는 좌표 단위로 계산한다. MVP에서는 청력 거리를 장애물과 관계없는 유클리드 거리로 계산한다.

```text
청력 거리 ≤ 슬라임의 청력 범위
→ 명령 전달
```

```text
청력 거리 > 슬라임의 청력 범위
→ NOT_HEARD
```

## 스탯 레벨

각 스탯은 0레벨부터 5레벨까지 존재한다.

- 슬라임 종류는 네 스탯의 초기 레벨 조합을 결정한다.
- 같은 종류의 슬라임은 같은 기본 스탯 조합으로 등장한다.
- 강화는 실제 속도값을 직접 수정하지 않고 스탯 레벨을 올린다.
- 스탯별 실제 수치는 중앙 레벨 표에서만 관리한다.
- 초기 슬라임은 원칙적으로 0~3레벨 범위에서 시작한다.
- 4~5레벨은 강화로 도달하는 상위 구간이다.

### 유효 레벨

```text
개별 유효 레벨
= 종류 기본 레벨
+ 해당 슬라임의 개별 강화
```

```text
최종 스탯
= 개별 유효 레벨에 대응하는 수치
+ 전체 강화 보정
```

유효 레벨은 최대 5레벨로 제한한다.

## 작업 속도

작업 속도는 슬라임이 직접 수행하는 상호작용의 소요 시간을 결정한다.

```text
실제 작업 시간 = 작업 기본 시간 ÷ 작업 속도 배율
```

| 레벨 | 속도 배율 | 기본 4초 작업의 실제 시간 |
|---:|---:|---:|
| 0 | 0.70배 | 5.71초 |
| 1 | 0.85배 | 4.71초 |
| 2 | 1.00배 | 4.00초 |
| 3 | 1.20배 | 3.33초 |
| 4 | 1.45배 | 2.76초 |
| 5 | 1.75배 | 2.29초 |

### 작업 기본 시간

| 작업 | 기본 시간 | 작업 속도 적용 |
|---|---:|---:|
| 물건 집기·내려놓기 | 0.8초 | 적용 |
| 재료 씻기 | 3초 | 적용 |
| 재료 손질하기 | 4초 | 적용 |
| 요리 담기 | 1.5초 | 적용 |
| 서빙하기 | 1.5초 | 적용 |
| 작업대 청소하기 | 4초 | 적용 |
| 냄비에서 익기 | 10초 | 미적용 |

불 위에서 익는 시간처럼 슬라임이 직접 작업하지 않는 시간에는 작업 속도를 적용하지 않는다.

## 이동 속도

이동 속도는 타일 위에서 슬라임이 움직이는 속도를 결정한다.

| 레벨 | 이동 속도 |
|---:|---:|
| 0 | 초당 1.6타일 |
| 1 | 초당 1.9타일 |
| 2 | 초당 2.2타일 |
| 3 | 초당 2.5타일 |
| 4 | 초당 2.8타일 |
| 5 | 초당 3.1타일 |

이동 속도는 경로 선택에는 영향을 주지 않는다. 같은 경로를 더 빠르게 이동하게 한다.

## 청력

청력은 플레이어의 음성 명령을 들을 수 있는 최대 거리를 결정한다.

| 레벨 | 명령을 들을 수 있는 거리 |
|---:|---:|
| 0 | 2타일 |
| 1 | 3타일 |
| 2 | 4타일 |
| 3 | 5타일 |
| 4 | 6타일 |
| 5 | 7타일 |

명령을 들었는지는 명령이 확정된 순간의 플레이어와 슬라임 위치로 판정한다.

- 범위 안에 있으면 명령을 전달한다.
- 범위 밖에 있으면 `NOT_HEARD`로 처리한다.
- 범위 밖의 명령을 다른 내용으로 잘못 수행하게 만들지 않는다.
- 명령을 듣지 못한 슬라임에게는 잠시 동안 `귀에 빗금` 아이콘을 표시한다.
- 팀 명령도 각 슬라임이 자신의 청력 범위에 따라 개별적으로 듣는다.

목소리 크기는 현재 MVP의 청력 계산에 포함하지 않는다. 청력은 플레이어가 주방 안에서 슬라임에게 가까이 가야 하는 이유를 만드는 공간 스탯으로 사용한다.

## 집중력

집중력은 슬라임이 기억할 수 있는 대기 작업의 수를 결정한다.

| 레벨 | 기억 가능한 원자 작업 수 |
|---:|---:|
| 0 | 1개 |
| 1 | 2개 |
| 2 | 3개 |
| 3 | 4개 |
| 4 | 5개 |
| 5 | 6개 |

`GET`, `MOVE`, `CHOP`처럼 실제 행동 시스템이 실행하는 최소 작업 하나를 원자 작업 하나로 계산한다.

```text
"버섯 가져와서 손질해."

GET(mushroom)
MOVE(cutting-board)
CHOP(mushroom)
```

위 명령은 원자 작업 3개를 기억해야 한다.

- 필요한 작업 수가 집중력 한도를 초과하면 명령을 시작하지 않고 `TOO_COMPLEX`로 처리한다.
- 작업 중 새 명령을 받았을 때 남은 기억 공간이 부족하면 기존 작업을 덮어쓰지 않고 `QUEUE_FULL`로 처리한다.
- 추상화 명령은 게임 코드가 먼저 세부 작업으로 분해한 뒤 각 슬라임의 집중력 한도를 검사한다.
- 팀 명령은 전체 작업을 역할별로 나눈 뒤 각 슬라임에게 배정된 작업 수를 검사한다.

## 슬라임 종류

슬라임의 종류가 기본 스탯 레벨을 결정한다. 개별 슬라임의 실제 속도값을 별도로 생성하지 않는다.

| 종류 | 작업 속도 | 이동 속도 | 청력 | 집중력 | 특징 |
|---|---:|---:|---:|---:|---|
| 너드 슬라임 | 2 | 0 | 1 | 3 | 느리게 이동하지만 복잡한 주방 작업을 잘 기억함 |
| 날쌘 슬라임 | 1 | 3 | 1 | 1 | 이동과 서빙에 유리하지만 긴 명령에는 약함 |
| 쫑긋 슬라임 | 1 | 1 | 3 | 1 | 멀리서도 명령을 받아 맵 반대편 작업에 대응하기 쉬움 |
| 일꾼 슬라임 | 3 | 1 | 0 | 2 | 가까이에서 지시해야 하지만 손질과 청소가 빠름 |

초기 시연에서는 위 종류 중 3종만 사용해도 된다. 종류를 추가할 때는 새로운 스탯을 만들지 않고 네 스탯의 레벨 조합으로 차이를 표현한다.

주방과 서빙은 슬라임 종류가 아니라 현재 배정된 역할이다. 같은 종류의 슬라임도 라운드 편성에 따라 주방 또는 서빙 역할을 맡을 수 있다.

## 강화

라운드 사이 선택지에서 스탯 레벨을 강화할 수 있다.

### 개별 강화

특정 슬라임 하나의 특정 스탯 레벨을 1 올린다.

```text
[말랑 집중력 강화]
말랑의 집중력 +1
```

### 전체 강화

모든 슬라임에게 적용되는 특정 스탯의 기본 보너스를 1 올린다. 강화 이후 새로 합류하는 슬라임에게도 적용한다.

```text
[전체 청력 강화]
모든 슬라임의 청력 +1
```

전체 강화는 각 슬라임의 실제 레벨이 아닌 스탯을 변화시킬 수 있다.

### 새로운 슬라임 합류

새로운 슬라임은 선택지에서 합류한다.

- 고용비는 존재하지 않는다.

## 슬라임 정보 표시

모든 슬라임은 머리 위에 자신의 이름을 항상 표시한다.

이름 근처에는 현재 상태를 나타내는 아이콘을 하나 표시한다. 여러 상태가 동시에 발생해도 가장 중요한 상태 하나만 표시한다.

| 우선순위 | 상태 | 아이콘 예시 |
|---:|---|---|
| 1 | 명령을 듣지 못함 | 귀에 빗금 |
| 2 | 명령이 너무 복잡함·기억 공간 부족 | 느낌표 또는 머리 아이콘 |
| 3 | 사고 발생·도움 필요 | 물음표 |
| 4 | 재료 운반 | 상자 또는 재료 |
| 5 | 손질 | 칼 |
| 6 | 조리 | 냄비 |
| 7 | 서빙 | 접시 |
| 8 | 이동 | 발자국 |
| 9 | 대기 | 말줄임표 |

오류 아이콘은 원인을 확인할 수 있도록 잠시 유지한다. 정상 작업 아이콘은 현재 행동이 바뀌면 함께 변경한다.

슬라임 선택 화면에는 네 스탯을 0~5개의 칸 또는 점으로 표시한다. 플레이 중에는 모든 수치를 계속 노출하지 않고 이름과 행동 아이콘만 표시한다.

## 요리와 판매 가격

MVP의 기준 요리는 버섯 스튜 한 종류다.

### 버섯 스튜 제작

```text
버섯 가져오기
→ 버섯 손질하기
→ 냄비에 넣기
→ 10초 동안 익히기
→ 그릇에 담기
→ 서빙하기
```

### 기준 가격

| 요리 | 기준 가격 | 주문 제한 시간 |
|---|---:|---:|
| 버섯 스튜 | 100G | 60초 |

## 실패와 패널티

패널티는 플레이어가 같은 실수로 시간과 돈을 동시에 과도하게 잃지 않도록 설계한다.

대부분의 슬라임 사고는 직접적인 금전 손실보다 작업 지연으로 처리한다. 손님에게 실제 영향을 준 주문 실패와 품질 저하만 매출에 직접 반영한다.

| 사건 | 직접 금전 패널티 | 추가 결과 |
|---|---:|---|
| 명령을 듣지 못함 | 없음 | 다시 가까이 가서 명령해야 함 |
| 집중력 부족 | 없음 | 명령을 짧게 나누거나 다른 슬라임에게 배정 |
| 슬라임이 버섯을 먹음 | 없음 | 재료가 3초 후 다시 생성됨 |
| 잘못된 작업대에 도착 | 없음 | 작업이 진행되지 않음 |
| 제한 시간 초과 | 수익 - 요리 가격의 50%G | 주문 실패 처리 |
| 잘못된 요리 서빙 시도 | 수익 -30G | 주문은 유지되며 올바른 요리를 다시 요구 |

제한 시간을 초과한 주문은 판매 수익을 발생시키지 않고 기준 가격의 50%를 수익에서 차감한다. 버섯 스튜의 경우 50G가 차감된다.

잘못된 요리를 서빙하면 30G가 차감되지만 기존 주문은 유지된다. 올바른 요리를 다시 만들어 제한 시간 안에 서빙할 수 있다.

## 라운드 경제

MVP에서 매출은 고용비를 지불하기 위한 화폐가 아니라 라운드 목표와 점수를 나타낸다.

### 1라운드 기준값

| 항목 | 값 |
|---|---:|
| 라운드 시간 | 180초 |
| 목표 매출 | 300G |

성공 여부는 다음과 같이 판정한다.

```text
수익 ≥ 목표 매출
→ 성공

수익 < 목표 매출
→ 실패
```

라운드 사이의 슬라임 합류와 강화 선택에는 별도의 구매 비용을 사용하지 않는다.

## 밸런싱과 비그래픽 시뮬레이션

게임 규칙은 Phaser의 그래픽 표현과 분리한다. 그래픽을 실행하지 않고도 동일한 게임 로직을 입력하고 결과를 확인할 수 있어야 한다.

### 입력

- 타일 맵
- 슬라임 종류와 위치
- 개별·전체 스탯 강화
- 주문 생성 시각
- 플레이어 명령과 명령 시각
- 랜덤 시드

### 출력

- 최종 라운드 점수
- 완성·실패한 주문 수
- 주문별 처리 시간과 판매 가격
- 슬라임별 이동 거리와 작업 시간
- 들은 명령과 듣지 못한 명령
- 집중력 초과로 거부된 명령
- 발생한 사고와 시각

동일한 입력과 랜덤 시드를 사용하면 동일한 결과를 재현해야 한다.

이 시뮬레이션을 사용해 목표 매출, 주문 간격, 스탯 레벨별 수치와 패널티를 그래픽 구현과 독립적으로 조정한다.

## 초기 구현에서 고정할 값

해커톤 첫 구현에서는 다음 값을 고정한다.

- 스탯 레벨 범위: 0~5
- 초기 슬라임 종류: 3종
- 동시 활동 슬라임: 최대 3마리
- 레시피: 버섯 스튜 1종
- 라운드 시간: 180초
- 목표 매출: 300G
- 주문 제한 시간: 60초
- 추상화 명령: 재료 준비 또는 버섯 스튜 만들기 중 1종

밸런싱 결과에 따라 중앙 레벨 표와 가격표만 수정한다. 슬라임 인스턴스마다 실제 속도나 가격을 별도로 조정하지 않는다.
