# 다음 개발 작업: 상호작용 코어 완성

## 목적

- 변경된 마우스 조작을 실제 게임 플레이로 연결한다.
- 복수 선택된 슬라임의 오브젝트 상호작용을 처리한다.
- 하나의 요리 제작부터 제출까지 전체 흐름을 완성한다.

## 1. 복수 슬라임 상호작용

- 복수의 슬라임을 선택한 상태에서 오브젝트를 우클릭할 수 있다.
- 선택된 슬라임들은 해당 오브젝트로 이동한다.
- 작업 가능한 슬라임 중 가장 먼저 도착한 한 마리만 상호작용을 시작한다.
- 나머지 슬라임은 대기 상태로 전환한다.
- 작업을 수행할 수 없는 속성의 슬라임은 작업을 거부한다.
- 작업 거부 시 로그를 출력한다.
- 작업이 끝난 슬라임은 대기 상태로 전환한다.

## 2. 재료 부족 처리

- 작업 오브젝트에 필요한 재료가 없으면 작업을 시작하지 않는다.
- 작업을 맡은 슬라임은 해당 오브젝트 앞에서 대기한다.
- 필요한 재료가 오브젝트에 들어오면 자동으로 작업을 시작한다.

## 3. 오브젝트 상태

- 대기
- 재료 부족
- 작업 중
- 작업 완료

- 작업 중인 오브젝트는 현재 작업 중인 슬라임을 기억한다.
- 작업 중인 오브젝트에는 다른 슬라임이 동시에 작업하지 않는다.
- 작업 진행도를 화면에 표시한다.

## 4. 첫 요리 제작 흐름

- 재료 상자에서 버섯을 가져온다.
- 버섯을 조리 도구에 넣는다.
- 불 슬라임이 조리 도구와 상호작용한다.
- 작업이 완료되면 버섯 구이가 생성된다.
- 버섯 구이를 제출대로 운반한다.
- 제출이 완료되면 목표 수량이 증가한다.

## 5. 구현 순서

- 복수 선택 상태에서 오브젝트 우클릭 처리
- 선택된 슬라임의 오브젝트 이동
- 가장 먼저 도착한 작업 가능 슬라임 판정
- 나머지 슬라임의 대기 전환
- 작업 가능 속성 판정
- 재료 부족 상태 처리
- 재료 추가 시 자동 작업 시작
- 작업 진행도 처리
- 완성 음식 생성
- 완성 음식 운반
- 제출 처리
- 목표 수량 증가

## 6. 완료 조건

- 여러 슬라임을 선택해 하나의 오브젝트에 명령할 수 있다.
- 한 오브젝트에서는 한 마리만 작업한다.
- 작업 불가능한 슬라임은 작업을 수행하지 않는다.
- 필요한 재료가 없으면 작업이 시작되지 않는다.
- 재료가 추가되면 대기 중인 슬라임이 작업을 시작한다.
- 작업 완료 후 버섯 구이가 생성된다.
- 버섯 구이를 제출하면 목표 수량이 증가한다.
- 음성 입력 없이 제작부터 제출까지 진행할 수 있다.
